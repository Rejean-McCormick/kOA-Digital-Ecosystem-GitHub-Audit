# Automatic, evidence-backed validations (v0.21.0)

The user never needs to click a manual validation button for a result independently verified in the bundled evidence review.

The dashboard intentionally displays three short labels:

- **✓ Validé**: a precise, already checked control supported by an authenticated, clickable historical source or a hash-checked JUnit result. The scope of the validation is that of the cited item, not the entire application.
- **Présent dans le code**: a source-attributed implementation observation, **not** a test outcome.
- **À vérifier**: the corresponding check lacks verified evidence. This is not a failure.

In particular, a filename such as `test_api.py` does not produce a green tick. Verified expert documentary conclusions are displayed immediately, independent of whether the private manual registry already has that record. This view never overwrites the user's local registry and never alters frozen historic campaigns.

Individual security practices from the 53-item reference catalogue have **zero automatic passes** unless a source-linked per-control check exists. A passing Security Gate test suite is shown as a validated test suite; it is not 53 security certifications.

On GitHub Pages, private evidence remains unavailable and none of these local results are silently published.
