# Characters and Collections

A Karacter profile combines identity, preferences, emotions, inner world, narrative conflicts, relationships, and visual identity. The name and current universe do not determine personality.

## Character anatomy

| Area | What it records |
|---|---|
| **Identity** | Name, role, universe membership, keywords |
| **Polarities** | Contextual paired preference axes (0–6 + 0–6 = 6) |
| **Emotional palette** | Emotions the character may experience; not a permanent mood |
| **Inner world** | Values, motivation, fear and habitual reaction |
| **Narrative** | Desire, need, limiting belief, contradiction, turning point, possible growth |
| **Relationships** | Other character IDs, relationship type, context, history and tension |
| **Story** | Canonical events explicitly approved by the author |
| **Visual signature** | Description, recognizable anchors, exclusions and artwork slots |

## Create, edit, duplicate or delete

1. In the sidebar, select a character or click **New character**.
2. Use **Create** for identity and visual signatures. Change the **universe** field there if you need to move the character.
3. Use **Understand** for polarities, emotions, motivations, fears, narrative depth, relationships and milestones.
4. Use **Duplicate** to make a new editable profile. The copy is a new character, not an additional portrait slot for the same person.
5. Use **Delete** only when intended. Karacter asks for confirmation and reports the number of associated relationships and images. Deletion is intended to remove related portraits and character relationships as one transaction.

Save changes are asynchronous and debounced. Watch for **Saved locally**. If you see **NOT SAVED**, use **Retry save** and protect your work with a backup.

## Start from an archetype

In **Create**, open the template picker for **12 optional starting points**. A template seeds fictional preferences and ideas; it is not a test, diagnosis, or immutable class. See [Archetypes and Situations](Archetypes-and-Situations).

## What a universe does

A universe (stored internally as a collection reference) determines where a character appears in the library. A character can only have one primary universe value at a time, but the sidebar can show **multiple universes simultaneously**. These filters do not change the personality or artwork.

## Example: King Klown

King Klown is a fictional trickster/strategist whose source-aware profile may include creative interpretations. His teal-and-cosmic visual design is an identity anchor; the separate mythic/canon forms are not automatically interchangeable individuals. Consult [King Klown Universe](King-Klown-Universe) for distinctions and provenance.

## Character data vs. story data

An individual character TXT export includes the profile, not necessarily the **shared** narrative timeline or image bytes. Use a **complete ZIP/JSON backup** for your whole working universe. See [Character Sheets and Backups](Character-Sheets-and-Backups).
