# Provenance, identity and references

Arketype's classifications are **descriptions of possible knowledge-state shapes**, not registered logical commitments. Each template is a neutral local workspace with a unique identity; an instance must receive a new identity from the Authoring Kit.

A source citation is not itself proof that a claim is true. A proof-map shortcut must point to an exact external proof and its scope. An authored testimony records what a participant said; it cannot silently become a factual finding. An event timeline is distinct from inferred causation.

The lifecycle is deliberately separated: **authoring → local checks → build → qualification → publication → optional activation**. A reader projection, repository hosting location, compression layout or HTML catalogue does not change the logical identity of its source state.

The file-level `INVENTAIRE.json` is an archive inventory for local integrity checking. Its byte hashes are not the Framework's logical commitments and do not confer canonical status.
