# Kristal v8

**Historical standard version:** `8.0.0`
**Current hosted-network architecture:** see [[Kristal-v10]]; v9 semantic state is documented in [[Kristal-v9]].

Kristal v8 is the compatibility-preserving capability layer that standardized:

1. **Language Layer** — external lexical Kristals and deterministic lexical resolution;
2. **AI Query Layer** — rebuildable indexes, typed exact query, evidence traversal and bounded AI context compilation.

```text
v6 portable truth + v7 semantic identity + v8 language/query capabilities
```

V9 does not remove these capabilities. It places them explicitly on the read/access side of a broader state architecture.
