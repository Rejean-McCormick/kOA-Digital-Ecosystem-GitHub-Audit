# Spek — Wiki

**Structured knowledge. Reusable forms. Multilingual publications.**

Spek 0.5.0 is an independent, local-first **semantic publishing and layout** engine. It binds typed semantic units and supplied short realizations to eight explicit editorial layouts, and emits static HTML, PDF and XeLaTeX with traceable source references. Spek does not decide which claims are true or eligible for public release.

**Core principle:** *Crystallize the form; vary the content.* A result, comparison, chronology, concept or argument is presented as an auditable composition rather than improvised long-form prose.

## Kristal → SemantiK Architect → Spek → Wiki

A **separate, optional integration overlay** adds Markdown Wiki draft generation to Spek; it is **not part of the unmodified Spek 0.5.0 snapshot**. The integration uses **Arketype** to choose an admitted editorial structure, **SemantiK Architect** to realize explicitly selected communicative content, and **Spek** to compose those realized units into GitHub Wiki Markdown.

- [[Kristal Wiki Architecture]] — Detailed roles, data flow and trust boundaries.
- [[Wiki Templates by Archetype]] — Correspondence between **19 Arketype profiles** and Spek's eight layouts.
- [[Wiki Draft Workflow]] — Local commands, private staging, validation and deployment boundary.
- [[SemantiK Integration]] — Existing fixture importer versus qualified live rendering.

**Not a live service:** updating this documentation does not install the overlay, generate real Kristal articles, authorize publication, enable a GitHub Wiki or push data to GitHub.

## Project status and responsibility

- **Shipped baseline:** Spek 0.5.0, eight layouts; FR/EN/IT; HTML, PDF, XeLaTeX, source traces; demonstrator and curated connectors.
- **Optional Wiki overlay:** typed archetype profiles, private Markdown drafts and SHA-256 verification, installed separately in Spek, Manager and `kristal-public`.
- **Not yet end-to-end:** automatic Kristal assertion selection → SemantiK requests/results → Spek realization bundles, as well as signed publication approval and wiki push.

The supplied demo sentences are fixtures, **not** authenticated SemantiK RuntimeSet outputs or certified scientific results. See [[Epistemic and Security Boundaries]], [[Roadmap]] and [[Publishing the Wiki]].
