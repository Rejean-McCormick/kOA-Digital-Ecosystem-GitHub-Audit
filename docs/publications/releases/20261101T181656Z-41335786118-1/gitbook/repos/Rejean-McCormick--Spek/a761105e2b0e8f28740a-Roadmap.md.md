# Roadmap and Integration Status

This page distinguishes what is shipped in Spek from an optional integration prepared for Kristal Wiki. It is **not** a certificate of release.

## Shipped Spek 0.5.0 (as inspected)

- Three scientific layouts: `result-card`, `argument-map`, `comparison`.
- Five educational layouts: `concept-card`, `learning-path`, `evidence-comparison`, `observation-inference`, `chronology`.
- Strict FR/EN/IT realization keys, HTML/PDF/XeLaTeX outputs and sidecar `document.json`.
- Source Explorer, verified site manifests, local compilation, curated connector previews.
- A separate, manually initiated GitHub Pages publication workflow and Spek software Wiki source.

## Optional integration overlay: Kristal Wiki / Arketype

A separate code overlay (not part of the clean Spek 0.5.0 snapshot) implements:

- `spek.wiki-archetype-templates/1.0` — compatibility profiles for 19 Arketype slugs;
- CLI: `list-wiki-templates`, `build-wiki`, `verify-wiki`;
- typed GitHub Wiki Markdown candidate pages and integrity manifests;
- integration hooks in Kristal-Manager and `kristal-public` for **private** collection drafts.

See [[Wiki Templates by Archetype]] and [[Wiki Draft Workflow]].

## Still required for real publication

1. Trusted adapter from approved Kristal assertions to explicit SemantiK communication projections.
2. SemantiK rendering with a released RuntimeSet supporting the requested content and language, plus independently checked coverage/provenance.
3. Mapping of the SemantiK results to Spek typed article slots and exact realization keys.
4. Verification of Framework identity/integrity, C1/C2/C3 publication gates and disclosure/linguistic review.
5. Separate, authorized push of reviewed Wiki Markdown to the GitHub Wiki repository, after enabling the Wiki.
6. Dedicated versioned Spek layouts for specialized topology, taxonomy or mathematical representations not faithfully captured by the current eight.

No general article planner, live Kristal publishing authority, implicit language fallback, arbitrary-layout interpreter or public Wiki deployment is claimed by the current integration.
