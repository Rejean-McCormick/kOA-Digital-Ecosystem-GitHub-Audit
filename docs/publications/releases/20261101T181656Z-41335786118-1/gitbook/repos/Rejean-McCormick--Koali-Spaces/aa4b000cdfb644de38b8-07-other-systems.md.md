# Autres systèmes : XKaliber, K-Port, EkoH, MediKristal

**Classe : Boundary d’intégration**

Ces systèmes doivent être intégrés uniquement lorsque leur runtime/UI officielle et leur ownership sont suffisamment définis.

- XKaliber : ne pas inventer une stack ou un runtime UI avant qu’il soit fixé.
- K-Port : définir la surface réelle avant onboarding.
- EkoH : respecter son rôle propriétaire ; ne pas le convertir en moteur de vote par commodité Koali.
- MediKristal : traiter avec prudence les capacités expérimentales et éviter toute inference clinique non définie.
