# ADR — Surface Layer

Toute modification d’un verrou `LOCK-KS-SURF-*` ou toute fermeture d’une décision `OPEN-KS-SURF-*` passe par un ADR dans ce dossier.

Le format minimal est `0000-template.md`. Le changement doit également mettre à jour la documentation canonique concernée, `locks/koali-surface-layer.lock.json`, les tests applicables et la qualification.
