# Knowledge-to-Action Loop

> **Reading model:** The main path explains what the kOA ecosystem enables. The technical reference explains how kOA-Linux hosts, isolates, verifies, and operates those capabilities. Product-specific details remain in each subsystem's own documentation.

## The collective cycle

```text
Know → Choose → Act → Remember → Know better
```

The expanded operational loop is:

```text
1. Observe and contribute
2. Structure meaning and preserve provenance
3. Compile reusable knowledge
4. Learn, consult, and deliberate
5. Produce explicit decision readings and outcomes
6. Convert outcomes into mandates, roles, cases, and tasks
7. Execute, escalate, close, and record evidence
8. Preserve institutional and cultural memory
9. Review results and update knowledge
```

## Systems along the loop

| Passage | Primary systems |
| --- | --- |
| Raw inputs → structured candidates | SenTient and deterministic ingestion tools |
| Structured candidates → portable knowledge | Kristal and validation workflows |
| Knowledge → learning and public collaboration | Konnaxion / KonnectED |
| Disagreement → structured deliberation | Konnaxion / Ethikos / Korum / Konsultations |
| Deliberation → multiple transparent readings | EkoH and Smart Vote |
| Accepted outcomes → organized execution | Governance rules and Orgo |
| Execution → cases, tasks, escalation, closure | Orgo |
| Results → memory and renewed knowledge | Kristal, operational records, cultural repositories, and audit evidence |
| Entire loop → local resilient operation | kOA-Linux |

## Why the transitions matter

A contribution is not automatically knowledge. Knowledge is not automatically a decision. A vote is not automatically authorization. A decision is not automatically work. Completed work is not automatically institutional learning.

Each transition requires declared authority, evidence, thresholds, roles, receipts, and a way to contest or repair the result.

## Example: a municipality

A flood-mitigation proposal can move from local reports and research, to structured knowledge, to public consultation, to a documented decision, to departmental cases and tasks, to implementation evidence, and finally to updated knowledge that improves the next planning cycle.

The value of the ecosystem is not one interface. It is the continuity of this chain.
