# Orgo

> **Reading model:** The main path explains what the kOA ecosystem enables. The technical reference explains how kOA-Linux hosts, isolates, verifies, and operates those capabilities. Product-specific details remain in each subsystem's own documentation.

Orgo is the organizational execution and operational-continuity system. It turns signals and decisions into Cases, Tasks, roles, routing, reactivity windows, escalation, closure, insights, and recurring review.

Use:

- [Orgo GitHub Wiki](https://github.com/Rejean-McCormick/Orgo/wiki)
- [Orgo repository](https://github.com/Rejean-McCormick/Orgo)
- [Public overview](https://initkoa.org/platforms/orgo/what-it-does)

kOA-Linux provides the runtime boundary; it does not redefine Orgo's internal object model or workflows.
