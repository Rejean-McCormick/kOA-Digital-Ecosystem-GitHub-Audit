# Koali Scenario Mosaic — naming conventions

## Canonical product name

**Koali Scenario Mosaic**

Use **Scenario** in the singular. In English compound nouns, the attributive noun is normally singular: `Scenario Mosaic`, not `Scenarios Mosaic`.

## Updated surfaces

The v3.6 rename is applied to:

- browser/page titles;
- site header branding;
- scenario-preview accessibility text;
- zero-install preview;
- generated preview builder;
- cover artwork text;
- README/project documentation;
- npm package name: `koali-scenario-mosaic`;
- product component name: `ScenarioMosaic.astro`;
- repository/archive name.

## Intentionally unchanged technical vocabulary

Generic implementation identifiers remain `mosaic-*` where they describe the mechanism rather than the product name, including:

- `mosaic.ts`;
- `mosaic.css`;
- `mosaic-layout.json`;
- `data-mosaic-*` attributes;
- `/uses/` public routes.

This avoids unnecessary route and implementation churn while keeping the public identity consistent.

## Koali capitalization

The canonical brand spelling is **Koali**. An all-capital rendering of the brand name is not permitted in public/editorial prose. Lowercase `koali` remains acceptable only where required by technical conventions such as npm package names or filesystem-safe identifiers.

Canonical positioning line: **Koali, the Sociotechnical Operating System**.
