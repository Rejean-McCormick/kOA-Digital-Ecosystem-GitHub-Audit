# FAQ

### Is Spek a new language model?

No. It composes *existing short expressions* into a structure with defined argumentative roles. SemantiK can be one realization provider.

### Does Spek write scientific paragraphs?

Not yet. Its central proposition is that a reader can understand many scientific ideas faster through reproducible result cards, argument maps and comparisons rather than invented transitions in free-form prose.

### Can I reuse a layout across research projects?

Yes. Slot contracts and dedicated renderers can be reused with different semantic IDs and expression bundles.

### Can I publish in other languages?

The current prototype explicitly supports English, French, and Italian. More languages require realization inputs, localized labels, tests and review; they are not automatically supported by SemantiK's experiments.

### Does `--production` make the research certified?

No. It checks declarations and pinned metadata. Authentic upstream scientific, translation and disclosure approvals remain separate.

### Is GitHub needed to compile?

No. Builds are local and offline. GitHub is an optional distribution/verification channel for vetted derived output.

### Is the wiki part of the same repository?

Wiki **source files** live in `wiki/`. The published GitHub Wiki is a second Git repository that must be initialized and synced explicitly.

### Why no license file?

The intellectual-property owner has not selected a distribution license. No open-source grant is assumed; see `LICENSE-DECISION.md`.

### Does Spek write the prose for a Kristal Wiki?

No. **SemantiK Architect** produces bounded expressions from an explicit semantic communication request; **Spek** arranges already supplied realizations into typed layouts selected in accordance with **Arketype**. The content-selection step is owned upstream by the Kristal publication process. See [[Kristal Wiki Architecture]].

### Can I run `build-wiki` on a clean Spek 0.5 checkout?

Not without the optional Spek/Arketype Wiki overlay. The clean snapshot ships eight layouts and HTML/PDF/TeX compilation, while the separately prepared extension adds the `build-wiki`, `verify-wiki`, and `list-wiki-templates` CLI commands.

### Does a successful Wiki draft mean the GitHub Wiki is online?

No. Draft compilation and SHA-256 verification are local checks. Signed publication approvals, GitHub Wiki activation, and a separate authorized push are still required.
