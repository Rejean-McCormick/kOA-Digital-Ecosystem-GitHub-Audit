# Integration

kOA integrations preserve owner boundaries and use explicit versioned contracts.

## Current layers

- **Product/system contracts** remain authoritative inside their owning systems.
- **EncyKlopedia** owns source acquisition/evidence handoff for knowledge-building scopes.
- **Da’at** maps source/IK-facing knowledge requests to Kristal-native contracts.
- **Kristal** owns referent/epistemic semantics and canonical epistemic artifacts.
- **UCKK / Univers-Cité** owns rebuildable consumer projections, not Kristal assertions.
- **Interaction Kernel** is the target system-of-systems protocol/Profile layer for selected cross-product interactions; adoption must be explicit.
- **kOA-Linux Release Sets** coordinate compatible platform artifact versions across release channels.
- **Koali Spaces** composes presentation surfaces without taking product authority.

## Key non-confusions

```text
IK Profile                  ≠ kOA-Linux internal contract unless adopted
acquisition evidence        ≠ epistemic validation
consumer projection         ≠ Kristal source of truth
consumer primary view       ≠ ecosystem ontology
derived glossary/index      ≠ parallel epistemic canon
Release Set                 ≠ Kristal validation/recognition
Space activation            ≠ Runtime Pack activation
kOA Node Agent operation    ≠ active Runtime Pack ownership
```
