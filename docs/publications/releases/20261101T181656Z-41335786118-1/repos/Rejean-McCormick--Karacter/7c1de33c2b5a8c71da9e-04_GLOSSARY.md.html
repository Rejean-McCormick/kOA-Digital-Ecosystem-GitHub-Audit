# Glossary (English canonical terms)

| Term | Meaning | Avoid confusing with |
|---|---|---|
| Character | Fictional entity with stable ID, narrative and preferences | A real person's psychological evaluation |
| Polarity | A linked pair of contextual preference tendencies | Independent skill scores or good/bad ranking |
| Pole | One side of a polarity | Moral virtue or flaw |
| Preference | Habitual priority when relevant choices are in tension | Absolute ability or permanent behavior |
| Balance (3/3) | Equal baseline emphasis between two poles | Neutrality as the best personality |
| Context | Circumstances determining whether a tendency is relevant | General trait label |
| Narrative conflict | Tension among values, needs, strategies or goals | A diagnostic symptom |
| Milestone | Author-recorded fictional change event | Automatic personality drift |
| Emotion | Temporary feeling in a situation | Stable personality |
| Reaction candidate | Hypothetical, editable possible response | A predicted fact or clinical result |
| Evidence trail | References to supplied fields and explicit inferences | External research proof or objective scoring |
| Scenario | Shared, neutral fictional facts and stakes | A fixed character response |
| Stakes | How much is at risk in the fiction | Moral quality of choices |
| Comparison | Side-by-side alternatives for two characters | Compatibility rating or competition |
| Theme | Reinterpretation of visual universe | Change to personality or narrative core |
| Visual signature | Reusable art-direction anchors | A single existing portrait file |
| Image mode | Portrait, four expressions or action | Visual theme |
| Asset slot | Exact `character/theme/mode` binding | A generic image attached to character |
| Full backup | Portable collection **including image bytes** | Browser autosave or TXT sheet |
| TXT sheet | Human-editable character text | Full image archive |
| Explorer | Simplified presentation of the same character data | Separate character model |
| Studio | Detailed presentation and advanced editing | A paid tier or different account |
