# Glossary

| Term | Meaning in Karacter |
|---|---|
| **Character** | A fictional profile with a stable ID and editable identity, preferences and narrative |
| **Universe** | A grouping of characters in the library (King Klown, Blank Universe, or a custom universe) |
| **All universes** | A visibility filter, **not** another universe |
| **Visual theme** | Reinterpretation of the same character's look without changing its personality |
| **Polarity axis** | Two labeled, contextual tendencies with linked scores totaling six |
| **Preference** | A usual creative tendency, **not** a level of ability, goodness or worth |
| **Emotional palette** | Possible recurring emotions, not a diagnosis or permanent emotional state |
| **Inner world** | Motivations, values, fears and patterns of interpretation |
| **Narrative contradiction** | Tension between a character's wants, beliefs, values and actions |
| **Archetype template** | Optional creative starting point; never a fixed identity |
| **Scenario** | A situation with context and stakes used to explore possible responses |
| **Simulation run** | Saved hypothetical results; **not** automatically canon |
| **Candidate** | One proposed reaction path with feelings, action, rationale and trade-offs |
| **Comparison** | Two characters considered under shared circumstances, without ranking |
| **Canon event** | A reaction/outcome explicitly accepted by the author as having occurred |
| **Story memory** | Approved past event that can inform later narrative suggestions |
| **Milestone / growth** | An authored change that can update a belief with an explicit action |
| **Portrait / expressions / action** | Three image modes with separate stored image slots |
| **TXT sheet** | Editable character record without the complete shared history or artwork bytes |
| **Full backup** | JSON/ZIP archive for complete workspace and images |
| **Provenance** | Traceable record of source text versus creative interpretation |
