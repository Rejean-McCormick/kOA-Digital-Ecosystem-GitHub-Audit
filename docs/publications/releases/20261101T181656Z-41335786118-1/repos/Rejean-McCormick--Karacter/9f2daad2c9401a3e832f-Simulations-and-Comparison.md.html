# Simulations and Comparison

Karacter uses a **local, deterministic, explainable narrative engine**. It does not call a language-model API or claim to predict real behavior.

## Simulate one character

1. Select a character, then open **Simulate**.
2. Choose a **scenario**, **stakes** (low, medium, high), and optionally another character as relationship context.
3. Click **Generate**.
4. Review **three possible reaction paths**. Each includes feelings, interpretation, action, underlying need, tension, upside, trade-off and an **Evidence** section.
5. Edit a candidate if its interpretation is wrong, or generate another set.

The evidence lists which character or context information the engine used. It is **storytelling rationale**, not scientific proof.

## Hypothesis, saved run, and canonical event are different

| State | Meaning |
|---|---|
| **Generated candidate** | A hypothetical path; no claim that it happened |
| **Saved simulation run** | A retained record you can reopen later |
| **Selected choice** | A response kept as the author's preferred option, but not necessarily story canon |
| **Canonical event** | The author explicitly chose **Make canon** and confirmed an outcome |

Only a canonical event is used as an approved **story memory**. See [Story Memory and Growth](Story-Memory-and-Growth).

## Compare two characters fairly

1. Choose Character A as the active character.
2. Select Character B in the **Comparison** area.
3. Set shared stakes and use **Compare**.
4. Read both sets of suggested reactions and the explanatory contrasts.
5. Reopen previous comparisons from the **comparison history** and export a comparison TXT if useful.

The comparison never awards a "winner," a compatibility score, or a moral rank. The goal is to expose different plausible interpretations of **the same situation**.

## History and cleanup

Simulation runs and comparisons can accumulate. **Clean unused history** removes unreferenced runs after confirmation; runs used by comparisons or canonical story events are protected. Export a backup first if you need to keep an archival copy.

## Example discussion prompt

**Situation:** Two allies disagree about whether to enter an unknown place. One usually plans carefully; the other prefers taking initiative. Ask *what each notices, what each fears, and what compromise the relationship makes possible*—not which personality is better.
