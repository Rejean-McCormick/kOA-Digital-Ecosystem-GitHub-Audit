# Accessibilité

**Classe : Normatif**

Minimum : landmarks sémantiques, skip links, focus visible, keyboard order déterministe, accessible names, contraste suffisant, zoom/reflow, reduced motion, focus restoration, drawers/dialogs keyboard-operable, annonces d’état pertinentes.

La couleur seule ne doit jamais être l’unique marqueur du changement d’application ou d’état.

Le mode immersif doit conserver une commande de retour Koali accessible et restaurer correctement le focus.
