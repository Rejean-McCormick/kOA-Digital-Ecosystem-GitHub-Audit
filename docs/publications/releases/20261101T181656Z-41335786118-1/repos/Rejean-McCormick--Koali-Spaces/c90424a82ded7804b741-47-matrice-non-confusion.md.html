# 47. Matrice de non-confusion

| Élément | Propriétaire | Koali peut présenter | Koali peut décider |
|---|---|---:|---:|
| Module selector | Koali Spaces | Oui | Présentation seulement |
| Sidebar contribution | Module + Koali composition | Oui | Ordre/présentation selon Space |
| Route contribution | Module manifest | Oui | Admission/namespace seulement |
| Business route interne | Application propriétaire | Oui | Non |
| Business data | Application propriétaire | Oui | Non |
| Business permissions | Application/Governance owner | Oui comme résultat | Non |
| Surface display mode | Koali Spaces | Oui | Oui, UX uniquement |
| Context accent | Koali Spaces | Oui | Oui, UX uniquement |
| Runtime target admission | kOA/Koali runtime boundary | Non comme donnée métier | Oui, technique |
| Konnaxion state | Konnaxion | Oui | Non |
| Orgo Case/Task | Orgo | Oui | Non |
| UCKK academic state | UCKK-Moodle | Oui | Non |
| Kristal epistemic status | Kristal authorities/contracts | Oui | Non |
| EkoH score | EkoH | Oui si disclosure autorisée | Non |
| XKaliber assessment | XKaliber | Oui | Non |
| K-Port admissibility | K-Port | Oui | Non |
