# Kristal Catho — Practical Example

## Keep the existing location

The Kristal stays in its existing local directory:

```text
C:\mycode\Kristal\locals\A-Kristal-Catho
```

**Do not move this directory** to use Konstellation. In `config/local-catalog.json`, the discovery root is `C:/mycode/Kristal/locals`, while `readModels.A-Kristal-Catho` refers to the **derived** graph stored within Catho.

## Reading path

```text
A-Kristal-Catho/
  kristal.workspace.json
  state/state-snapshot.json
  build/v9/...                (local state and artifacts, if present)
  derived/catho-graph/
    manifest.json
    nodes.json
    edges.json
```

The v10 reader preserves the Framework's v9 semantic states and accepts the `node-edge-json/1` recipe when configured. For the derived graph, it validates file paths and the declared hashes of canonical inputs. It does not rewrite `canon/`.

## What you should see

- **Domain-oriented perspectives** upon opening, not only a single technical “V9 state” object.
- Navigation paths for people, works, themes, sources, assertions, and unconfirmed hypotheses.
- Navigable relationships, search, and permitted provenance information.
- In the October 17 French-display patch: readable labels for a **limited set of mapped relations**, fewer irrelevant Astrolabe hits, and less prominent technical facets.
- Known example: `P138` displays **« Nommé d’après »**; the source predicate is retained. Unknown Wikidata properties are not assigned guessed meanings.
- A **derived local reading** notice rather than a “demo corpus” banner.

In tests using the October 17 semantic-display patch with Catho, the derived graph contained **4,527 entities**, **13,217 assertions**, and **50 relation definitions**. The two observed `P138` edges received **« Nommé d’après »** as their display label. These are **results for a particular test corpus**, not Kristal-standard invariants, a general language guarantee, or independent historical validation.

## v9 and v10 are compatible

`schema_version: "9.0"` describes a **semantic state**. Framework **v10 draft.3.2** adds hosting and discovery architecture without making this v9 state obsolete. Local reading is neither v10 publication nor C1/C2/C3 qualification.

## If Catho will not open

- Confirm that `kristal.workspace.json` exists at the expected location.
- Check `config/local-catalog.json` and `readModels` paths.
- Check the freshness of `kristal.discovery.json` and `derived/reader-inventory.json` with the **Authoring Kit/Manager**. A `stale` inventory should be regenerated by the Kit, without altering the canon.
- If a relation registry exceeds the limit of **10 domain types per definition**, use the Konstellation reader with relation partitioning. Do not delete links to satisfy the schema.

For labels like `academicien_sur_liste_publiee`, Konstellation uses **« Source attestant une inscription sur une liste d’académiciens »**. This is deliberately a source-oriented label, not an assertion that Manager or the viewer has established the person's membership. The same caution applies to saintliness and other historical claims.
