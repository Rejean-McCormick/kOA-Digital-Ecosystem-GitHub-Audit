# Generated Content Policy

## 1. Role

Generated content accelerates discovery, traceability, and AI context assembly.

## 2. Authority

Generated content is a derived projection. Manual edits are prohibited and cannot create authority.

## 3. Rebuild

Every generated artifact is reproducible from source contracts and metadata. A clean rebuild must match committed output.
