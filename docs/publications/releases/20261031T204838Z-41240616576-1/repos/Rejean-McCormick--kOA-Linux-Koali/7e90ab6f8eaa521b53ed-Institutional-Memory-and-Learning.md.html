# Institutional Memory and Learning

> **Reading model:** The main path explains what the kOA ecosystem enables. The technical reference explains how kOA-Linux hosts, isolates, verifies, and operates those capabilities. Product-specific details remain in each subsystem's own documentation.

Memory is not one database. It is the reconstructable relationship between knowledge, decisions, work, evidence, culture, and later review.

The ecosystem preserves complementary forms of memory:

- **Kristal** — claims, provenance, uncertainty, semantic relations, and versions;
- **Orgo** — signals, cases, tasks, ownership, escalation, outcomes, and recurring operational patterns;
- **Konnaxion** — learning, proposals, deliberation, public outcomes, projects, and cultural participation;
- **Kreative / Konservation** — cultural works with context, rights, consent, authority, and exhibitions;
- **kOA Mediatheque** — local media and file authority;
- **governance and audit services** — policies, decisions, receipts, exceptions, and recourse;
- **kOA-Linux** — backup, restore, portability, and continuity of local operation.

Memory becomes learning when results update knowledge, procedures, curriculum, policy, and the next cycle of action.
