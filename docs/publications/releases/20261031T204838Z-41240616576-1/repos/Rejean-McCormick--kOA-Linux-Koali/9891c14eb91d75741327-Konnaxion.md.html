# Konnaxion

> **Reading model:** The main path explains what the kOA ecosystem enables. The technical reference explains how kOA-Linux hosts, isolates, verifies, and operates those capabilities. Product-specific details remain in each subsystem's own documentation.

Konnaxion is the public, civic, learning, cultural, and collaboration platform of the kOA ecosystem.

This Wiki does not reproduce its module specifications. Use:

- [Konnaxion GitHub Wiki](https://github.com/Rejean-McCormick/Konnaxion/wiki)
- [Konnaxion repository](https://github.com/Rejean-McCormick/Konnaxion)
- [Public overview](https://initkoa.org/platforms/konnaxion)
- [Modules and submodules in this Wiki](Modules-and-Submodules)

At the kOA-Linux boundary, Konnaxion remains an independently owned system. kOA-Linux defines only deployment, resources, trust, storage exposure, health, offline behavior, integration, backup coordination, and safe degradation.
