# Responsive scenario image pipeline — V2.2\n\n## Purpose\n\nPreserve the visual scenario image slot while serving smaller files at the actual display sizes used by the Mosaic. This restores the V1 image-preparation behavior without making final artwork mandatory for every V2 scenario.\n\n## Source contract\n\nOptional masters live in:\n\n```text\nsrc/assets/scenario-images/SCN-001.png\n...\nsrc/assets/scenario-images/SCN-036.png\n```\n\nEach committed master must be a valid **1254×1254 PNG**. Any other PNG name or size fails image preparation.\n\n## Generated public contract\n\n`npm run images:build` creates:\n\n```text\npublic/scenarios/images/SCN-001-418.png   # 418×418\npublic/scenarios/images/SCN-001.png       # 627×627 canonical default\n```\n\nThe resize pipeline uses Sharp, `sharp.kernel.lanczos3`, `withoutEnlargement: true`, PNG compression level 9 and adaptive filtering. Files are written through temporary files and validated before atomic replacement. Processing is limited to two scenarios at a time.\n\nOld `836` and `1254` responsive outputs are removed. The 1254 master remains only under `src/assets/scenario-images/`.\n\n## Production fallback\n\nThe build does not require all 36 masters. If a master is absent but an existing square public PNG of at least 627 px is available, that public file is used to rebuild the 418/627 set. If neither exists, the scenario continues to use its V2 family SVG fallback.\n\n## Runtime loading\n\n`src/lib/scenario-image.ts` exposes only existing responsive candidates. A final image normally renders as:\n\n```html\n<img\n  src=\"/scenarios/images/SCN-001.png\"\n  srcset=\"/scenarios/images/SCN-001-418.png 418w, /scenarios/images/SCN-001.png 627w\"\n  sizes=\"(min-width: 901px) 292px, (min-width: 721px) 220px, (min-width: 363px) 210px, 58vw\"\n>\n```\n\nThe zero-install preview uses the same `srcset`/`sizes` contract and copies the generated public scenario assets into `preview/assets/scenarios/`.\n\n## Commands\n\n```bash\nnpm install\nnpm run images:build\nnpm run images:validate\nnpm run build\n```\n\n`npm run build`, `npm run dev`, and `npm run preview:offline` invoke image preparation automatically.\n
