# Glossaire

| Terme | Définition |
|---|---|
| Adapter | Couche de confiance qui transforme une source en structures lisibles par Konstellation en déclarant ses pertes. |
| Affordance | Possibilité de navigation dérivée de la structure observable. |
| Canonique | État autoritatif du Kristal. |
| Constellation | Renderer de voisinage relationnel borné ; pas synonyme de Konstellation. |
| Context fingerprint | Références immuables définissant corpus, registry, policy et contexte d'exécution. |
| Evidence | Élément soutenant un record/assertion. |
| Focus | Entité ou zone actuellement inspectée. |
| Lens | Perspective déclarative de navigation. |
| LOD | Level of detail : représentation progressive ou agrégée selon volume/zoom. |
| NavigationHints | Indications déclaratives non factuelles pour améliorer le planning. |
| NavigationPlan | Contrat dérivé décrivant recettes et actions disponibles/recommandées. |
| Profiler | Composant qui dérive les affordances structurelles. |
| Projection | Représentation calculée et reconstructible d'un sous-ensemble visible. |
| Provenance | Origine et chaîne de transformation d'un élément. |
| QuerySpec | Contrat de sélection explicite de l'utilisateur. |
| Reader Policy | Règles de visibilité appliquées avant toute sortie. |
| Recipe / recette | Intention de navigation associée à une projection et un renderer. |
| Renderer | Composant contrôlé réalisant visuellement une recette. |
| Renderer Registry | Registre approuvé des renderers disponibles. |
| ResultSet | Résultat paginé d'un QuerySpec. |
| Shell | Grammaire d'interaction stable de Konstellation. |
| Witness | Référence expliquant pourquoi un élément satisfait un critère de QuerySpec. |
