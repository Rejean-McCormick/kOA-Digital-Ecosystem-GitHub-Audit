# Surfaces globales

**Classe : Normatif**

Les surfaces globales appartiennent à Koali Spaces parce qu’elles agrègent ou décrivent l’expérience elle-même.

Elles consomment des providers/adapters non autoritatifs. Elles n’accèdent pas directement aux bases de données des owners.

Ordre d’implémentation recommandé : Home -> Health -> Offline -> Settings -> Search -> Tasks.
