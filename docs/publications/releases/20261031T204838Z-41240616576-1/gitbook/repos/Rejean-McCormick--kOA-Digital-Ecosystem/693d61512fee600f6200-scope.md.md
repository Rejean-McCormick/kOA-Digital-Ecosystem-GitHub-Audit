# Scope

This repository is authoritative only for ecosystem-level mappings, cross-system invariants and optional correlation evidence.

It may document:

- owner boundaries;
- cross-system contracts/Profiles and adoption status;
- how product/platform artifacts are referenced;
- lifecycle separation;
- kOA-Linux release-channel/Release Set mapping;
- `kristal_runtime` versus kOA Node Agent responsibility;
- Koali Spaces presentation boundary;
- implementation-status gaps between owners;
- source-corpus/repository discovery metadata used for reconciliation;
- UCKK-Moodle/Konnaxion and kOA-Linux/UCKK boundary mappings when supported by owner contracts;
- SemantiK Architect / GF / release-orchestrator boundary mappings when supported by owner contracts;
- derived conceptual/classification views, provided they do not redefine owner or contract authority.

It does not redefine:

- Konnaxion civic models;
- Orgo Task/Case/Workflow internals;
- Kristal schemas/epistemic semantics;
- kOA-Linux platform component/artifact/release contracts;
- Koali Spaces Surface Layer/Space model contracts;
- SemantiK Architect internal NLG contracts;
- UCKK-Moodle internal plugin/domain contracts, Moodle capabilities or Assembly rules;
- GF Wordbench/GF Observatory internal language-engineering contracts;
- SemantiK Runtime Orchestrator internal release-transaction implementation;
- repository presence as proof of integration, adoption, qualification or deployment;
- Klassification coordinates, passage labels or views as technical contract identifiers.
