## Current architecture gap

The previous A014 T0 implementation demonstrated Orgo ingestion and Case/Task creation using a UCKK-centered decision trigger. That evidence remains useful technically, but the authority model is now superseded.

The next implementation must prove:

```text
Konnaxion/eThikos decision
        ↓ direct
Orgo Signal
        ↓
exactly one governed business consequence
```

with stable source identity, correlation, authentication, and replay-safe idempotency.

The exact Konnaxion decision identifier is intentionally not invented in this status page; it must come from the actual implementation contract.

## Safety / ownership invariants

- Konnaxion/eThikos owns decisions made in Konnaxion/eThikos.
- Orgo owns workflow orchestration, Case/Task state, and its IntegrationOperations.
- Konnaxion owns Konnaxion mutations and provider receipts.
- UCKK is optional for publication/diffusion in this integration.
- Cross-system SQL is prohibited.
- `accepted` is not terminal success when the contract is asynchronous.
- Redrive reuses existing durable work and preserves idempotency.
- Runtime secrets do not belong in docs, scenario packs, or audit payloads.
