# kOA and UCKK Mediatheques

> **Reading model:** The main path explains what the kOA ecosystem enables. The technical reference explains how kOA-Linux hosts, isolates, verifies, and operates those capabilities. Product-specific details remain in each subsystem's own documentation.

The Mediatheque relationship is one infrastructure topic inside the larger ecosystem.

- **kOA Mediatheque** — local, private-by-default, offline authority for media and files held by the installation.
- **UCKK Mediatheque** — online authority for content accepted by the external UCKK Moodle platform.

They may implement compatible frames for identity, versions, hashes, metadata, provenance, rights, restrictions, relations, collections, languages, renditions, and lifecycle. Compatibility does not create a shared database, shared authority, or automatic synchronization.

See [Files, Media, and Provenance](Files-Media-and-Provenance) and [UCKK](UCKK).
