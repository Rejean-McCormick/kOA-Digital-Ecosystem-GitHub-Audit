# Kristal Integration Pack Wiki

**Version: 0.3.0-alpha.1 · Status: integration candidate, not production-qualified**

The Kristal Integration Pack connects selected **Konstellation**, **Kompiler**, **Kristal Framework v11**, **diK**, and **Kristal Authoring Kit** workflows without making itself an identity authority, canonical editor, or publisher.

It has two independent integration paths:

1. **Framework v11 read-only tools:** validate semantic inputs, calculate lexical coverage, generate a derived reading view, and preflight diK dictionary handoff to the Authoring Kit.
2. **Legacy Konstellation/Kompiler bridge:** query local Kompiler, produce a Context Pack and, when a suitable v7 Surface exists, request a *derived* v6 projection. Historical overlay installation is guarded and **not appropriate for an already integrated Konstellation checkout**.
