# Richer previews and capability keywords

Koali is the ecosystem. Public scenario paragraphs explain the human situation and the concrete knowledge-to-action transition Koali preserves; they do not enumerate internal component brands.

Target preview length is approximately 40–55 words, with a 28–72 word validation envelope.

The eight human-facing tags remain primary. Their architecture associations are revealed on hover or keyboard focus. Smart Vote, EkoH, and SemantiK appear only as discreet `Repères / Keywords` on scenarios selected for public discoverability, and these keywords are searchable.

The current empty-preview prompt and mobile swipe interaction remain intact.

Human problem first. Koali action second. Architecture discoverable on demand.
