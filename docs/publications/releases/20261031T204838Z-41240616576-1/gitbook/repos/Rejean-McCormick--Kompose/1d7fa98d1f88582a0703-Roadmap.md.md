# Roadmap — Gaps, Not Product Promises

The following is a **proposed roadmap**, not a committed schedule. The current source package is `0.2.0` and remains a local technical reference.

## Already available for local experimentation

- Reference contracts and fictional Rivers capsule.
- Pure session-state, role quota, document-reading, prompt and dependency examples.
- Kontexte B6 **synthetic plan compiler**, including restricted projections, absence *proposal* and mock-receipt replay.
- Ekole P1 **strict local synthetic teacher-preview verifier**.
- Tests for local rule behavior, safety rejections and optional wiki structure.

## Next: agree on operational contracts and owners

- Formalize the adopted Orgo ownership decision (ADR 0008) across every integration interface.
- Reconcile Kontexte curriculum references and obtain human pedagogical approval: `qc-pri-ma-006` in the bakery fixture must not be silently mapped to `qc-pri-ma-008`.
- Agree on Orgo Case/Task/Signal and WorldRelease verification contracts, acceptance tests, access model and rollback process **before** implementing a real adapter.

## Before any real classroom use

- School SSO, real teacher authorization, tenant/World permissions and release verification.
- Transactional workflow in **Orgo** with retries, idempotence, durability and audit.
- Accessible student and teacher interfaces (Ekole/KOR or other approved clients), secure data retention/deletion, and validated educational content.
- Pedagogically defensible diagnostic, role allocation, fairness, teacher review and school approval.
- Operational, security, privacy and accessibility tests with accountable institutions.

**Not production-ready:** documentation does not replace actual implementation, formal security testing or signed release authorization. See [[Project-Status]] and [[Tandem-Orgo-Boundary]].
