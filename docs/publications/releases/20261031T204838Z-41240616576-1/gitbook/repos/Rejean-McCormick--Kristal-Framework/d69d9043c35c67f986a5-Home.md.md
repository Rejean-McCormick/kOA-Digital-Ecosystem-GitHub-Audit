## Three separate responsibilities

- **Canonical semantic identity** is namespace-scoped `KQ` (entity or concept), `KP` (property), `KA` (assertion) and `KS` (source). Natural-language words and directly copied Wikidata Q/P IDs **do not** become canonical graph identities.
- **Lexical dictionaries** attach words/aliases to KQ/KP for a particular language. Per-language completeness is measured rather than presumed; a fallback is not a translated term.
- **External crosswalks** document and review KQ↔Wikidata Q / KP↔Wikidata P. A future Wikidata entry can be mapped to an existing KQ without changing the historical KQ or committed source.

**Important:** text remains valid as an explicitly typed literal (documents, citations, string-valued properties). The prohibition concerns structural **semantic identity**, not all words in a Kristal.

## Ecosystem scope

**Framework** defines schemas/TCK and reference validators; **Authoring Kit `4.0.0-draft.3`** optionally builds strict v11 authoring profiles; **diK `1.0.0-alpha.7`** offers a local CLI for dictionary inspection, Wikidata-local lexical imports and KQ/KP coverage; **Arketype `1.5.0`** creates optional blank v11-ready scaffolds and can request read-only diK reports. No one component's metadata inspection qualifies all the others.
