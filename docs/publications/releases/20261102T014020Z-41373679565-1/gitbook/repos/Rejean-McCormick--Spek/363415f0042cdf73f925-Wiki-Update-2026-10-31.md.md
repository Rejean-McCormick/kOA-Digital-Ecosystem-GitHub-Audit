# Spek Wiki documentation update — 31 October 2026

This documentation package is based on the supplied `Spek.wiki.zip`, the `znapshot_Spek_10311553.zip` source snapshot, the corresponding Arketype and SemantiK Architect designs discussed in the project, and the **separate** `OVERLAY_SPEK_WIKI_ARKETYPE_2026-10-31.zip` integration package.

## Documentation changes

- Corrected the 0.5.0 baseline to **eight layouts**, not three.
- Documented **19 Arketype** profiles and their admitted Spek layout set.
- Clarified SemantiK's role as the **realization engine**, Spek's role as the typed **template composer**, and Manager's publication responsibility.
- Documented the optional Wiki Markdown CLI (`build-wiki`, `verify-wiki`, `list-wiki-templates`), required private bundle inputs and safe demo workflow.
- Separated the software documentation Wiki (`Spek.wiki.git`) from the target Kristal knowledge Wiki (`kristal-public.wiki.git`).
- Clarified that the integration overlay is **not the same thing as an installed or live feature**. This ZIP only updates documentation.

## Publication and archive hygiene

The delivered updated Wiki ZIP intentionally excludes the `.git/` folder embedded in the upload. The Git working copy and remote/branch settings on the user's PC must remain untouched. All existing `.bat` and `.pyw` support files are copied without modification.

No Git commit, GitHub push, release signing, live rendering of the five Kristals, or Wiki enablement is performed by this documentation update.
