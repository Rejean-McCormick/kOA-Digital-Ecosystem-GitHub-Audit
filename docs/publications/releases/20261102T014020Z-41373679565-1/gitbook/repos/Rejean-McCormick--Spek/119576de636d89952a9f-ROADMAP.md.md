# Roadmap

This is a proposal, not a promise of delivery.

## 0.1 — Experimental foundation (included)

- Three audited scientific layouts.
- FR/EN/IT fixed-language realizations and no silent fallback.
- Local HTML, ReportLab PDF, and XeLaTeX sources.
- Reference-based input preflight, manifest, tests, and gated deployment template.
- Historical SemantiK fixture importer and English GitHub wiki source.

## 0.2 — Rendering and semantic fidelity (included)

- Shared document model, per-language inspectable JSON and visible semantic trace across formats.
- Portable installed Unicode font handling, corrected PDF demo pagination, full UI localization.
- Regression tests of fidelity, links and rendering invariants.

## 0.3 — Layout authoring (planned)

- General-purpose renderer for typed slot JSON contracts.
- JSON Schema specifications and a formal backwards-compatibility policy.
- Preview diagnostics explaining unused units and omitted optional slots.
- Responsive accessibility and PDF/HTML parity tests.

## 0.4 — Verified semantic bridge

- Read-only upstream projection adapter with canonical JCS commitment verification supplied/approved by Framework owners.
- Qualified, signed SemantiK RuntimeSet and per-phrase provenance bindings.
- Linguistic review attestations and cross-language equivalence reports.

## 0.5 — Scholarly distribution

- Bibliographic metadata, ORCID, citations, CSL, Crossref/JATS export as appropriate.
- DOI/release integration with manual scientific approval.
- Archival and reproducible release packaging.

## 1.0 consideration

Independent scientific validation and upstream governance decisions are prerequisites; passing tests alone does not make the system production-ready.

## After 0.3

- Integrate qualified SemantiK token / GF-feature mappings with explicit provenance and review.
- Evaluate Source Explorer readability and accessibility on real, permissioned Kristal states.

## v0.4 implementation status

- Delivered: offline Konstellation ResultSet importer, generic exchange adapter, explicit opt-in Konstellation query capture, configurable outbound deep links, AI-preconstructed phrase importer, distinct channel provenance, and Source Explorer source-system references.
- Not delivered: Konstellation-side navigation button, live bridge against deployed servers, generalized Kristal canonical cryptographic verification, LLM generation, native SemantiK Architect runtime execution or automatic publication.

## Spek v0.5 educational extension

Spek now also supports curated, read-only Ekole/Kompose **public/demo excerpts** using `spek.educational-projection/1`. Five versioned educational layout contracts are independent of the source adapter. See [Educational Layouts](EDUCATIONAL_LAYOUTS.md), [Educational Connectors](EDUCATIONAL_CONNECTORS.md), and [Educational Privacy](EDUCATIONAL_PRIVACY.md). Spek neither orchestrates missions nor certifies curricula nor authorizes restricted static publication.
