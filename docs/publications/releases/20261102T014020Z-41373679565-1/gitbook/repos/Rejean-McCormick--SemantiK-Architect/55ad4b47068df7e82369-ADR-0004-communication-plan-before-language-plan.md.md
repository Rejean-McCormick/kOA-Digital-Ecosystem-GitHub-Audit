# ADR-0004 — Language-neutral CommunicationPlan before target LanguagePlan

Status: **accepted**

## Context

Final segmentation/construction may legitimately differ by language.

## Decision

Communication planning fixes obligation grouping/order/discourse constraints; LanguagePlan decides target-language block topology and realization units.

## Consequences

Avoids English-like presentation assumptions while preserving global communication intent.
