# Documentation Contract

## 1. Metadata

Active Markdown begins with valid KOA metadata containing a unique doc_id, class, status, language, layer, scope, and references.

## 2. Structured Sources

JSON contracts declare a stable identity, version, status, schema, scope, dependencies, and validation-relevant data.

## 3. No Parallel Inventories

A source file is discoverable from its location, schema, and metadata. Adding it does not require editing a second manually maintained list.

## 4. References

Local references use safe repository-relative paths. Missing required references block validation.
