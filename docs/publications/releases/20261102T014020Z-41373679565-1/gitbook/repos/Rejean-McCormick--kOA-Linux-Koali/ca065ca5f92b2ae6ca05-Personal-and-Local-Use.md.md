# Personal and Local Use

> **Reading model:** The main path explains what the kOA ecosystem enables. The technical reference explains how kOA-Linux hosts, isolates, verifies, and operates those capabilities. Product-specific details remain in each subsystem's own documentation.

A lightweight local profile can provide:

- Ariane-assisted navigation;
- selected Kristal runtime packs;
- local kOA Mediatheque files and media;
- personal or small-team Orgo work;
- selected Konnaxion spaces or portable capsules;
- installed language artifacts;
- offline reading, editing, backup, and queued exchange.

Heavy compilers, research workbenches, large search engines, and local AI models remain optional or run on other nodes. UCKK is not required for local education or media use.
