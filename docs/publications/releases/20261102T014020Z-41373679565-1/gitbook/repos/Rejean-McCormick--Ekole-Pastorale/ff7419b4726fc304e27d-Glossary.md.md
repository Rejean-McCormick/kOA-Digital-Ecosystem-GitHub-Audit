# Glossary

| Term | Meaning in this repository |
| --- | --- |
| **Ekole Core** | Neutral, standalone educational engine in sibling directory `ekole/` |
| **Ekole Pastorale** | Catholic content repository `ecole-pastorale/`, loaded by Core |
| **Content pack** | Ekole-readable derived manifest and course files; currently `ekole.content-pack/0.1` |
| **Canonical source** | Authoritative educational payload and registered semantic material in a Kristal workspace |
| **Kristal** | Independently structured and validated knowledge or educational workspace |
| **Kristal Framework v11** | Semantic and authoring conventions used by these workspaces (`11.0.0-draft.3` in the supplied snapshot) |
| **Arketype** | Template/archetype system used to create standardized Kristal workspaces |
| **ARK-20** | Candidate federated-learning-unit archetype, slug `unite-formation-federee` |
| **ARK-21** | Candidate witness/virtues/sources archetype, slug `temoin-vertus-sources` |
| **KQ / KP / KA / KS** | Namespace-scoped semantic identities for entities, properties, assertions, and sources |
| **v9 commitment** | Logical state/build commitment binding canonical content to a verifiable snapshot |
| **Projection** | Deterministic transformation from validated Kristals into Ekole-facing content files |
| **Teacher view** | Generated `cours/` JSON including teacher-oriented assessment and session guidance |
| **Learner view** | Generated `publications/eleve/` JSON with private teacher fields excluded; draft only |
| **Catho bridge** | Hash-pinned inventory connecting to historic A-Kristal-Catho artifacts; not a v11 semantic crosswalk |
| **Doctor of the Church** | Catholic title bestowed on recognized teachers; do not equate every attributed opinion with official doctrine |
| **Witness Kristal** | Documentation of a saint or other witness, distinct from the course interpreting that life |
| **Ecclesiastical approval** | Review or authorization by a competent Church authority, not inferred from software tests |
| **`fr-CA`** | Canadian French; current language of course content and lexicons |
