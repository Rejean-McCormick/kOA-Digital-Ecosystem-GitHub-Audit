# Role entry points

Professions are useful as examples, but they should not become the primary taxonomy. Use them as **entry points into recurring patterns**.

## Executive / manager
Usually enters through: understand signals, choose, allocate, organize, verify outcomes, preserve reasons.

## Technician / operator
Usually enters through: receive contextual work, diagnose, consult expertise, act, verify, record the result.

## Researcher / analyst
Usually enters through: find sources, reconstruct context, compare hypotheses, collaborate, preserve provenance, publish.

## Teacher / trainer
Usually enters through: structure knowledge, teach, connect practice to evidence, improve materials, disseminate.

## Designer / creator
Usually enters through: research, co-create, preserve the why, compare versions, move from idea to production.

## Public servant / community organizer
Usually enters through: collect signals, connect public knowledge and expertise, deliberate, decide, route work, explain publicly.

## Emergency / field coordinator
Usually enters through: maintain shared situation, mobilize roles, route work, operate offline if necessary, record outcomes.

## Archivist / curator / knowledge steward
Usually enters through: provenance, semantic relationships, versions, preservation, interpretation, public access.

## Principle

The role page should always point back to **patterns**, not imply a separate Koali product for each profession.
