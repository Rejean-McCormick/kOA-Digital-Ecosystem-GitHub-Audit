# Karacter — Character Psychology Studio

**Documentation for Karacter 7.4 · English · Local-first**

**Create · Understand · Simulate · Remember · Evolve · Visualize**

Karacter is a bilingual (English/French) creative studio for designing fictional characters. Instead of labeling traits as *good* or *bad*, it explores **paired personality preferences**, internal conflicts, relationships, and context-dependent choices. Its offline simulation engine offers possible responses; the author decides which events become part of the character's story.

> **Not a psychological diagnostic tool.** The scales are fictional design aids, not measures of human ability or worth. Reactions are explainable storytelling suggestions, not predictions about real people.

## What ships in 7.4?

Two built-in universes, in this order:

1. **King Klown** — 39 source-aware character profiles from the Kristal MEDIA and King Clown Canon packs on a clean installation.
2. **Blank Universe** — John Doe, a deliberately minimal character with no prescribed psychological profile.

**All universes** is a filter, not a third universe. Existing users can also have custom universes and previously saved characters; their counts may differ from a clean installation. The earlier sample Mira is preserved on an existing installation but not added to new ones.

You do **not** need to import the built-in characters. There is one **Import file** action for standardized TXT/JSON/ZIP data.

## Core workflow

1. Select an existing character or start one from scratch.
2. Define identity, habitual personality preferences, values, fears, contradictions, and relationships.
3. Simulate a situation and review **three possible responses** with supporting reasons.
4. Optionally choose a response as **canon** and describe its outcome.
5. Generate an image prompt, then import the externally generated artwork.
6. Save a complete ZIP backup with image bytes.
