# Exclusions actuelles

**Classe : Normatif**

Ne pas intégrer comme application Koali Spaces :

- Ame-Artificielle ;
- VotingMachine / VM Engine.

Cette exclusion ne supprime pas les fonctions AI optionnelles appartenant à d’autres produits et ne supprime pas les concepts Smart Vote internes à Konnaxion/UCKK lorsqu’ils sont déjà définis par leurs propriétaires.
