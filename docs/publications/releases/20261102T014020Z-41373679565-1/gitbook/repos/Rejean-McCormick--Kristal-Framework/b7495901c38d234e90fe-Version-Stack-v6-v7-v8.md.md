# Version Stack: v6 → v7 → v8

> **Historical page:** this page explains the stack before v9. For the v9 state model see [[Version-Stack-v6-v7-v8-v9]] and for v10 see [[Version-Stack-v6-v7-v8-v9-v10]].

## v6

Portable epistemic state, assertions, valuations, applicability, provenance/evidence, roles and deterministic state identity.

## v7

Stable semantic identity (`KQ/KP/KA/KS`), registries, Mesh/KOS, axes, factorization and projections.

## v8

External language/lexical layers, exact KQP query, rebuildable read models, bounded AI contexts and semantic fingerprints.

Valid v6 or v7 artifacts can participate in v8 without being rewritten. V9 preserves the same rule and adds representation-independent state/lifecycle on top.
