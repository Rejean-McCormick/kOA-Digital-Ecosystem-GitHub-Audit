# Blank Universe

**Blank Universe** is the second default universe in Karacter 7.4. It is intentionally open-ended: no story, species, genre or visual aesthetic is imposed.

## John Doe: the minimal starting point

A clean installation includes **one character**, **John Doe**, in Blank Universe.

The default profile deliberately has:

- A name, universe membership and stable ID.
- **No polarities**.
- **No emotions** selected.
- **No motivation, values, fear, internal conflict, growth or visual signature** defined.

This is not an error or unfinished character. John Doe is a blank slate for creating your own personality model.

## A good first exercise

1. Select **Blank Universe** and **John Doe**.
2. Give John Doe a new name and role if you wish.
3. Under **Understand**, add just **two or three relevant polarity pairs**. You do not need to fill every possible axis.
4. Add one desire and one fear that can create tension.
5. Write a small relationship context and run a low-stakes scenario.
6. Decide whether any result belongs in **Story**.

You can also click **New character** to leave John Doe untouched and create additional Blank Universe profiles.

## Does Blank Universe stay blank?

Only the initial **starter profile** is minimal. Once you edit it or add more characters, the universe naturally becomes your own project. Karacter does not wipe changes during ordinary launches, and a deliberate deletion should not be undone by automatic reseeding after the initial migration.

## Template choice

A template is optional. If you use one, it supplies some defaults; it does not make Blank Universe part of King Klown. Universe membership and character personality remain separate concepts.
