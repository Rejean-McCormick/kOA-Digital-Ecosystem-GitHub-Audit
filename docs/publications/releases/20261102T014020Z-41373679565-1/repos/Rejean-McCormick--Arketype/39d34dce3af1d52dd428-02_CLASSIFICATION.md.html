# Classification method

Arketype supports **19 candidate archetypes**, grouped for navigation into five families: **Knowledge, Composition, Structures, Processes and Sources**. These are browsing aids, not exclusive kinds in the Kristal Framework.

An archetype can be described along multiple independent axes: native topology, semantic ownership, epistemic status, time orientation, executable dynamics, federation, intended readers, lifecycle and granularity. A distributed educational reference, for example, can be both a semantic cluster and a layered projection without becoming a new standardized native type.

## Structural patterns

The shared visual grammar includes: `linear`, `branching`, `hub`, `cluster`, `tree`, `timeline`, `matrix`, `casefile`, `multilayer` and `network`. One primary pattern is a useful illustration, but it is **not** a formal schema or a constraint on every possible reader view.

See `inventaires/grammaire-visuelle.json` for the visual descriptions; `inventaires/archetypes-visuels.json` is the descriptive index linking each archetype to its primary and secondary patterns.
