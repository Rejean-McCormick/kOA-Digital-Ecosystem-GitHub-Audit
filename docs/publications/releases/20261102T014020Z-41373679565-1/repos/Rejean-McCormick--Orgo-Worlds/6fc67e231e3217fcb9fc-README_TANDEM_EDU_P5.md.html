# P5 WORLDS - signé, hors ligne, sans autorisation runtime

Dans le dépôt racine, exécuter PREVIEW_TANDEM_EDU_P5_WORLDS.cmd, puis INSTALL_TANDEM_EDU_P5_WORLDS.cmd et VERIFY_TANDEM_EDU_P5_WORLDS.cmd. Sauvegarde externe au dépôt dans Tandem_Local. En cas de problème : ROLLBACK_TANDEM_EDU_P5_WORLDS.cmd. Aucune route, DB, service ou VPS.
