# SemantiK Architect

**SemantiK Architect (SA)** is a deterministic multilingual **semantic-to-human communication engine**.

It receives **structured meaning** selected by an upstream system and turns that meaning into faithful, context-appropriate communication in a requested language.

> **Core rule:** upstream systems decide **what must be communicated**; SemantiK Architect decides **how all of it is communicated**.

## Canonical flow

```text
Upstream domain / Kristal / semantic source
                  │
                  ▼
          CommunicationRequest
     ┌────────────┼─────────────┐
     │            │             │
SemanticGraph  Obligations  CommunicationContext
     └────────────┼─────────────┘
                  ▼
        CommunicationPlanner
                  ▼
          CommunicationPlan
                  ▼
      Lexical knowledge preflight
                  ▼
           LanguagePlanner
                  ▼
             LanguagePlan
                  ▼
          Exact lexical binding
                  ▼
       versioned SA ↔ GF bridge
                  ▼
              GF / PGF
                  ▼
        CommunicationResult
         + coverage + runtime ID
```

## What SA owns

SA owns articulation:

- grouping and segmentation;
- bounded multi-sentence communication;
- lists when appropriate;
- register, formality, politeness and audience adaptation;
- target-language construction choice;
- lexical orchestration;
- lowering to GF through a versioned contract;
- semantic coverage validation;
- deterministic runtime identity.

SA does **not** decide truth, relevance, priority, ethical correctness, workflow state, or which supplied facts may be discarded.

## Current implementation status

The v1 core is implemented: canonical semantic model, planners, lexical preflight/binding, RuntimeSets, capability profiles, strict SA↔GF bridge, PGF boundary, coverage, SDK/CLI/HTTP surfaces, conformance tooling and release validation.

A production language is available only when its own immutable RuntimeSet is released with a real PGF grammar, bridge, lexical artifacts, capability profile and passing conformance evidence.
