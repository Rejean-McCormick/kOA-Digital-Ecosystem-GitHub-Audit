# Visual system for presenting Koali uses

## 1. Palette chips
Represent the eight usage families as stable visual labels. Do not force one color to equal one software component; categories describe human intent, not architecture.

## 2. Component intensity
Use four compact bars or dot scales:

`Kristal ●●●●○`  
`Konnaxion ●●●○○`  
`Orgo ●●●●●`  
`UCKK ●○○○○`

These are editorial emphasis indicators, not measurements.

## 3. Pattern badge
Every scenario should show its `PAT-xx` family near the title. This is the bridge from concrete example to general mechanism.

## 4. Property badges
Show only when meaningful: `OFFLINE`, `MULTILINGUAL`, `LOCAL-FIRST`, `SENSITIVE DATA`, `AI-OPTIONAL`, `PUBLIC-FACING`, `HIGH-CONSEQUENCE`.

## 5. Loop strip
Use a compact flow such as:

`signal → context → people → decision → work → result → memory`

Do not force the full loop when the scenario naturally starts or ends elsewhere.

## 6. Evidence footer
Keep `COMPOSED · runtime UNVERIFIED` or equivalent visible in detailed views. Public marketing surfaces may simplify the label, but they must not strengthen the claim beyond its evidence.

## 7. Hero-card rule
Hero cards should show only: situation, one-sentence Koali value, pattern, short loop, and 2–4 strongest component indicators. Detailed evidence belongs one click deeper.
