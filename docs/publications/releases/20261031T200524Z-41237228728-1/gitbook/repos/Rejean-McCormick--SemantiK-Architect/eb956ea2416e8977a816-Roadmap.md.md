# Roadmap

The SA v1 core architecture and canonical pipeline are implemented. The next work is predominantly **release/integration work**, not creation of a second core.

## Immediate milestone — first real released language RuntimeSet

Take a mature GF language (Albanian is a natural current candidate) through the complete SA gate:

```text
real PGF
+ v1 SA↔GF bridge
+ lexical artifact
+ capability profile
+ conformance suite
+ passing evidence
→ RELEASED RuntimeSet
```

Then execute a real end-to-end semantic communication through SA and the concrete GF language.

## Product integration milestones

Build product-specific ACLs when upstream contracts are explicit:

- Kristal semantic/epistemic projection;
- Orgo task/workflow communication;
- eThikos structured thought/argument articulation;
- KeenKonnect/Konnaxion multilingual system communication.

## Language scaling

Once the first profile is proven end-to-end, scaling is primarily:

```text
GF language development
→ artifact build
→ SA conformance
→ RuntimeSet release
```

not modification of shared planning code.

## Later extensions

Only add these when justified by concrete requirements:

- richer discourse/anaphora strategies;
- additional SA↔GF operations;
- richer locale artifacts;
- more capability profiles;
- additional lexical source adapters;
- alternate realizers as explicit adapters (never silent replacements).
