# Modèle offline

**Classe : Normatif**

Koali distingue le shell local de la disponibilité réseau des fonctionnalités propriétaires.

Offline behaviors : `available`, `cached_read_only`, `degraded`, `unavailable`.

Un module peut rester visible en mode réduit ; un autre peut être omis. La policy du Space décide comment présenter les modules non disponibles.
