# Ariane

> **Reading model:** The main path explains what the kOA ecosystem enables. The technical reference explains how kOA-Linux hosts, isolates, verifies, and operates those capabilities. Product-specific details remain in each subsystem's own documentation.

Ariane represents interfaces, controls, actions, states, and relationships as a semantic navigation graph. It supports intent-based guidance, accessibility, and bounded automation without conflating navigation with authorization.

Use the [public Ariane overview](https://initkoa.org/technology/ariane) and [Assisted Navigation with Ariane](Assisted-Navigation-with-Ariane).

kOA-Linux provides local runtime, profile selection, permissions, resources, and optional external voice boundaries.
