# Document Lifecycle

## 1. States

Documents and contracts use explicit proposed, active, accepted, deprecated, superseded, retired, or archived states where applicable.

## 2. Activation

Activation occurs only after validation and generated-output checks pass for the complete documentation release.

## 3. Removal

A removed source is deleted from active discovery, references are updated, and generated outputs are rebuilt.

## 4. Recovery

A failed documentation activation restores the last verified release as one unit. It does not activate a second product model.
