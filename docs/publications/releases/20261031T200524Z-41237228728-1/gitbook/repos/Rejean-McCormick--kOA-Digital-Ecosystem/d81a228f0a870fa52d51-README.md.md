# Kristal v10 — Cross-repository harmonization (C0)

**Last coordination review:** 2026-10-12 · **Status:** plan and source-snapshot assessment, **not production qualification**.

This section tracks ownership, interface contracts, evidence, blockers, and approved human decisions for the transition to the Kristal **v10 hosted network**. kOA Digital Ecosystem is **C0 coordination only**: the owning repositories implement and qualify their own contracts. No document here authorizes a GitHub write or changes a canonical Kristal.

## Two lanes remain separate

**Frozen historical projection lane:** Kristal Standard 6.0.0 / IK v2 / `encyklopedia.corpus-harvest-handoff/1.0.0` / UCKK projection. It remains pinned in `../knowledge-projection-contract-set.json`, and must not be silently overwritten.

**Newer hosted-network lane:** v9 owns the logical semantic state and commitments; v10 (`10.0.0-draft.3.1` in provided snapshots) adds hosting, bindings, discovery, and controlled publication. GitHub is a *host profile*, not a new logical identity and not a source of factual authority.

## Navigation decision

**Konstellation is the user-facing navigator across Kristals and within a selected Kristal.** Manager is the authoritative operational *inventory of actual instances* and read-surface synchronization owner; Arketype is the non-normative *library of archetypes and structural patterns*. Konstellation can consume both through explicit read-only interfaces. GitHub collections show only accessible hosted surfaces; an absent public index does not erase local knowledge.

## What this document does not do

This section does not change the Framework, Kit, Manager, Bootstrap, public/private collections, domain knowledge, source data, repository visibility or a publication grant. An approval to automate qualified revisions after a first scoped authorization **is not** the authorization of any particular Kristal or file set.

**Source status:** based on code snapshots and coordination records. Current remote HEAD, ACLs, owner signatures, receipt verification and cross-repository deployment have not been established by these documents.
