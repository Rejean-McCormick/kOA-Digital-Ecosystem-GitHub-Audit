# SenTient

SenTient is an optional **extraction/resolution capability**, not the universal proposal boundary of the ecosystem.

Depending on the Profile it may consume source material, Claim-IR, Structured Epistemic State, Exchange fragments or dataset records and may produce Resolved Claim-IR, Structured Epistemic State updates, resolution bundles or candidate mappings.

## Constraints

SenTient:

- must preserve provenance and uncertainty;
- must not silently upgrade certainty, validation or recognition;
- must not assign authority recognition;
- must not mutate a Reference Exchange by side effect;
- is optional when a source already emits a supported Kristal-native structured input.

Claim-IR / Resolved Claim-IR remain valid compatibility and extractor profiles under Kristal v5, but kOA documentation must not present them as mandatory for every knowledge flow.
