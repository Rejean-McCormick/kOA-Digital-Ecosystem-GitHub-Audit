# Educational Layout Pack

Spek v0.5 adds five layouts: `concept-card`, `learning-path`, `evidence-comparison`, `observation-inference`, and `chronology`. They complement the three scientific layouts, **not** replace them.

Each template defines typed, cardinality-checked semantic slots, reused for HTML, PDF, and XeLaTeX. FR/EN/IT user-facing labels are localized; phrase content is always supplied, not inferred or translated by Spek. Every HTML card retains **Explore source**.

The fictional school-garden package demonstrates all five cards. It is not a vetted Ekole lesson, assessment, curriculum level or qualified SemantiK output.

See [[Ekole Integration]], [[Kompose Integration]] and [[Educational Privacy]]. Detailed contracts live in `docs/EDUCATIONAL_LAYOUTS.md`.
