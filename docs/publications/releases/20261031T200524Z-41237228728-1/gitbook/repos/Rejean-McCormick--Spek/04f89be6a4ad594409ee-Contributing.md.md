# Contributing

Spek welcomes issue reports, layout proposals and reproducible examples **without** confidential Kristal data.

1. Open an issue describing the reader goal, proposed semantic roles and affected trust boundary.
2. Change the typed layout spec and every supported renderer together.
3. Update localized labels (FR/EN/IT), engineering docs and wiki page.
4. Add positive tests, negative tests and at least one representative source/realization fixture.
5. Inspect HTML/PDF/TeX visually and open a PR documenting the review steps.

Use **English** for code documentation, governance and wiki writing. Multilingual article content is naturally acceptable. Do not add automatic public publishing or bypass source verification.

The repository does not yet grant an outbound open-source license. Consult `LICENSE-DECISION.md` before redistributing or accepting outside contributions.
