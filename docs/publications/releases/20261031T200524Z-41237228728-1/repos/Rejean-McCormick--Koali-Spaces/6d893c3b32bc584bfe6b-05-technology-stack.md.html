# Stack technique de référence

**Classe : Référence d’implémentation**

Baseline actuelle :

- Node.js 22 validé dans le workflow courant ;
- pnpm 10.20.0 ;
- Next.js 15.5.24 ;
- React 18.2.0 ;
- Ant Design 5.26.2 ;
- `@ant-design/icons` 5.6.1 ;
- `@ant-design/pro-components` 2.8.10 ;
- TypeScript 5.9.x ;
- Vitest 3.2.x ;
- Zod 3.25.x.

Cette stack est la référence du repository, pas une autorité universelle sur les applications hébergées. Une application propriétaire peut utiliser une autre stack si son transport d’intégration est conforme.
