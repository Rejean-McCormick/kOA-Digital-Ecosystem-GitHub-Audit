# Glossary

**Logical Artifact** — declared unit of the Kristal semantic model; its identity and commitment are not simply a file hash.

**Arketype** — nonnormative design library describing structures and usage profiles; it does not qualify canon.

**C1 / C2 / C3** — distinct independent qualification, authorization/policy, and hosting/publication functions, subject to their respective contracts.

**Canon** — state and content under a Kristal's authority; Konstellation does not modify it.

**Discovery** — noncanonical metadata used to guide readers and describe recorded files.

**Derived** — computed or projected, reconstructible object that does not replace canon.

**File fingerprint** — hash of a file's bytes; does not alone establish a logical State Commitment.

**Kristal** — knowledge workspace/unit with its own contracts and authority boundaries.

**Lens** — structured reading angle selected for a perspective.

**Manager** — operational inventory and checks of workspaces and metadata; not an epistemic authority.

**Navigation Affordance** — potential navigation path identified from visible structure.

**NavigationPlan** — explainable view recommendations based on the selection and visible content.

**Reader Policy** — content-access policy applied before queries and projections.

**Renderer** — controlled component presenting a projection DTO without changing logical content.

**State Commitment** — semantic commitment computed under the Framework contract; distinct from a file SHA or Git commit.

**Read Surface** — derived or hosted representation for consumers; it may be technical rather than semantic.

**v9 / v10** — v9 semantic-state model retained by the proposed v10 hosted-network architecture.

See the repository glossary `docs/26-glossary.md` and Framework glossary `docs/22_GLOSSARY.md`.

**Display label** — human-readable UI name for a source identifier or predicate; it does not alter the identifier or assertion.

**Wikidata property ID** — a technical `P…` identifier (such as `P138`), which may have an explicitly registered display label.

**Unresolved identifier** — a `P…` or `Q…` code for which the current local presentation dictionary lacks a grounded label; it remains visible instead of receiving an invented meaning.

**Semantic display layer** — the current noncanonical French presentation helpers in `src/lib/semantic-display.mjs`; **not** a universal translation or verification engine.

See [[Semantic Labels and Localization|Semantic-Labels-and-Localization]] and [[Astrolabe and Search|Astrolabe-and-Search]].
