# Spek — Wiki

**Structured knowledge. Reusable forms. Multilingual publications.**

Spek is an experimental, local-first semantic publishing engine. It binds **typed semantic units** and short multilingual expressions into a **library of reusable editorial layouts**, then emits static HTML, PDF, and XeLaTeX.

**The idea:** *Crystallize the form; vary the content.* A semantic claim can be presented as a scannable result card, an argument map, or a comparison without asking the language system to generate long continuous paragraphs.

## Trust and qualification

The demo is **not an empirical scientific result**. Its phrases are written test fixtures, not certified GF/PGF SemantiK RuntimeSet outputs. The compiler neither authenticates Kristal canonical commitments nor grants the right to publish. Read [[Epistemic and Security Boundaries]] before considering a real release.

## Project status

**0.5 experimental.** Eight layouts and three example languages; expandable in future releases. Documentation and code should be reviewed together. [[Roadmap]] · [[Contributing]] · [[FAQ]]

## Inspect each published card

In the HTML reader, select **Explore source** at the foot of any result, premise, qualification, or evidence card. Review its semantic identity, provenance and evidence, then inspect the words and any explicitly supplied linguistic features. The explorer does not fabricate missing morphological attributes. See [[Source Explorer]].

## v0.4: Autonomous Spek

Spek is not a Konstellation extension. It can import from multiple Kristal or external sources and accepts either SemantiK Architect phrases or preconstructed AI sentences, with distinct provenance. See [Standalone Architecture](Standalone-Architecture), [Source Connectors](Source-Connectors), and [Language Channels](Language-Channels).

## v0.5: Educational layouts and curated connectors

Five educational templates plus strictly filtered Ekole/Kompose preview imports. See [[Educational Layout Pack]], [[Ekole Integration]], [[Kompose Integration]] and [[Educational Privacy]]. No upstream curricular or access authority is transferred to Spek.
