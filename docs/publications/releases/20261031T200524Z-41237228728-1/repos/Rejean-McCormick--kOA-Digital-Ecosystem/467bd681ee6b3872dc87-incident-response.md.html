# Operations — incident response

Identify the owner of the failed state first.

- Konnaxion: civic/product state.
- Orgo: workflow/integration-operation state.
- Kristal: epistemic artifact semantics/evidence.
- `kristal_runtime`: Runtime Pack verification/active-state/runtime health.
- kOA Node Agent: privileged node-local lifecycle transition/receipt.
- kOA-Linux Release Set/channel: platform release compatibility.
- Koali Spaces: Space/presentation/runtime-registration state.
- Interaction Kernel: Profile/protocol conformance where adopted.

Do not repair another system's authoritative state with direct database writes or by creating a duplicate integration-layer state record.
