# Governance, Rights and Provenance

## License status

Kontexte's root `LICENSE-POLICY.md` currently states that **no repository-wide license has been granted**. This is important: a public GitHub repository is not automatically open source, and included educational content or derived catalogue data may have separate rights holders.

Before public release, authorized owners should decide and publish licenses or permissions for:

- Kontexte source code and contribution terms;
- original scenario and educational content;
- imported or derived Ekole reference material;
- images, illustrations, translations and audio;
- community-specific cultural knowledge with separate protocols where appropriate.

The source snapshots of Orgo, Orgo_Worlds and Ekole are **not** bundled in Kontexte merely because their contracts are referenced.

## Responsible educational use

- Keep versioned provenance for parent neutral frames and localized overlays.
- Require a qualified educator to review age appropriateness and assessment alignment.
- Do not confuse synthetic facts and real historical or scientific assertions.
- Use accurate and attributable sources for curriculum or cultural claims.
- Preserve independent consent and permission decisions for each identifiable media subject or artifact.
- Do not upload children’s identifying material, teacher answer keys or secure configuration into the source repository.

## Source documentation

The original Ekole–Orgo upgrade plan is archived under `docs/ekole-orgo/` and the Québec Grade 3 notes under `docs/locales/qc3/`. These documents are in **French** and contain a mixture of implemented facts, design decisions and proposals. The English Wiki summarizes these distinctions; it does not convert proposals into shipped features.

## Contribution policy

Until the rights holders resolve licensing, contributors should seek explicit permission before supplying code or scenarios intended for redistribution. The root `CONTRIBUTING.md` provides technical checks and safety rules, not a substitute for permission to use the underlying materials.
