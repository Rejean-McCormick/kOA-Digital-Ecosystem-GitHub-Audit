# Frequently Asked Questions

### Is Kontexte an alternative to Orgo?

**No.** Orgo is the sole operational orchestrator. Kontexte defines situations, projections, role descriptions, and adapter data. Solo and group missions alike are ultimately Orgo's responsibility.

### Does Kontexte replace Ekole's curriculum?

**No.** The curriculum is a reference and evidence system, while interdisciplinary situations may cross subject boundaries. Ekole owns knowledge and the educational validation process.

### Does the Québec Grade 3 extension fully satisfy official expectations?

Not yet. The 60 overlays and 83 internal candidate objectives represent a broad **planning inventory**, not expert-verified, fully taught or ministry-approved curriculum coverage.

### Are there already classroom-ready multi-learner missions?

No. The pilot scenario is described in detail, but the current Orgo fixture creates only a synthetic initial Case and preparation Task. Per-learner delivery, joins and live collaboration need further Orgo work.

### Can the same scenario include kindergarten through Grade 6?

By design, yes. The same neutral frame can support a whole-school event; different participants would receive different age-relevant objectives and support. This is a **design capability**, not evidence of a deployed mixed-grade runtime.

### Are the roles permanent identities?

No. A role can be chosen for a mission or activity. It is a narrative/visual perspective, not an authentication identity, medical label or lasting school classification.

### Is the neutral catalogue language-independent?

Its *problem structure* aims to be reusable across cultures, but its source JSON is currently written in **Canadian French**, and it contains human editorial assumptions that still require review. Neutrality is not guaranteed merely by a label.

### Does `--lang en` translate every page?

No. It selects existing English field values and falls back where absent; some generated site labels remain French. There is no automatic multilingual certification.

### Can Klownkoins be exchanged for real prizes or money?

Not through this software. Klownkoins are a fictional arithmetic and budgeting device. Any educator-approved classroom recognition must be arranged separately and fairly.

### Can a refusal to publish be handled by blurring a picture?

No. Public access to the original file, previews, EXIF and identifying tags must be blocked, not covered cosmetically. The current code only computes a conservative metadata manifest; it does not provide a production media service.

### Can I publish the repository under an open-source license now?

Only the rights holders can make that decision after checking the rights to the code and imported educational content. The current project **does not grant a repository-wide license**.

### Where is the full original Ekole–Orgo upgrade specification?

In the main repository's `docs/ekole-orgo/` directory, preserved in French. Begin with [Architecture](Architecture) and [Roadmap and Limitations](Roadmap-and-Limitations) for an English summary.
