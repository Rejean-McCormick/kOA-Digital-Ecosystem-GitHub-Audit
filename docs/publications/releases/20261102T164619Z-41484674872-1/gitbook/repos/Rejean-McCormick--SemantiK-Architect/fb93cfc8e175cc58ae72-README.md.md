# Architectural Decision Records

Status: **normative index**

Accepted ADRs define why locked architecture decisions exist. A later accepted ADR may supersede an earlier ADR, but the affected lock/schema must be updated in the same change set.

ADR numbering is immutable; never recycle an ADR number.

- `ADR-0013-wikidata-primary-generic-lexical-authority.md` — Wikidata Lexemes own generic lexical knowledge; GF/RGL owns grammar/realization.
- `ADR-0015-kristall-v7-ecosystem-boundary.md` — retain portable v6 SA ingress while aligning authority boundaries to Kristall v7.
