# 30. MediKristal : verrou de sécurité de positionnement

`LOCK-KS-SURF-103` — **Une surface MediKristal MUST afficher son statut de recherche/prototypage tant que le projet n'est pas validé pour usage clinique direct.**

`LOCK-KS-SURF-104` — **Koali ne présente pas un résultat MediKristal comme décision clinique autonome.**

`LOCK-KS-SURF-105` — **L'interface ne masque pas provenance, version, applicability ou protocol identity lorsque ces éléments sont requis par le résultat.**
