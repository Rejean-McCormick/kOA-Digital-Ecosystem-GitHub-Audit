# Change control et ADR

**Classe : Normatif**

Une modification requiert un ADR lorsqu’elle change une frontière d’autorité, un SurfaceKind, le modèle d’activation, l’isolation browser, le transport d’application, le modèle SSO, la propriété des routes ou une règle d’offline.

Une modification de style, texte, composant Ant Design ou structure interne de fichier ne requiert pas d’ADR si elle respecte les contrats.

Un ADR doit contenir : contexte, décision, alternatives, risques, impact sécurité/offline, impact sur les propriétaires et migration.

Les décisions ouvertes de la Surface Layer v1.1 restent gouvernées par sa documentation dédiée.
