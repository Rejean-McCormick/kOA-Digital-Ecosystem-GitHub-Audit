# Skope Wiki

**Skope 0.15.0-alpha.1** · Offline-first, local Wikidata discovery, scope exploration, QID inventories, full-record extraction, human-reviewed identity reconciliation, and **native Kristal portfolio enrichment**.

> **Status:** standalone prototype / working research tool. Wikidata discovery output is **not** automatically a verified identity, an occurrence record, a statement-level proof, or a publishable Kristal canon.

Skope connects to an **existing, finalized EncyK compact Wikidata SQLite index** without modifying it. You can search entities, define graph traversals as JSON recipes, preview networks and convergence candidates, run explicitly requested disk-backed QID collection jobs, and — provided that a verified dump and previously built random-access files are available — extract original Wikidata entity JSON records. Skope also supports a specialized Catho recognized-authors workflow and non-automatic identity review.

Skope 0.15 adds a **native command-line portfolio workflow**, able to inventory v11 Kristals, discover bounded Wikidata Q/P candidates, acquire verified full statements and produce non-canonical fact proposals. This feature has **no dedicated browser dashboard yet**. See [Portfolio Enrichment](Portfolio-Enrichment) and [Portfolio CLI Reference](Portfolio-CLI-Reference).

## Fundamental distinctions

1. **Compact index:** aggregated edges and labels, not raw Wikidata statements or their reference details.
2. **Scope preview:** at most 10,000 displayed nodes; a truncated preview does not mean a completed inventory.
3. **QID collection:** bounded by your explicit root, property filter and depth; geography and external convergence are **not** applied as filters by the mass collector.
4. **Full extraction:** requires an existing matched dump, verified manifest, existing locator/sidecars and an available random-access reader; it does not scan or reindex the source automatically.
5. **Identity ranking:** name and context heuristics are suggestions, **not probabilities or documentary identity proofs**.
6. **Portfolio (CLI):** bounded search candidates, even unique name hits, are *not* independently confirmed Wikidata identities. `A-Kristal` is never auto-selected as a tentative seed.
7. **Kristal:** a selected workspace is consulted read-only; Skope does not publish to its canon.
