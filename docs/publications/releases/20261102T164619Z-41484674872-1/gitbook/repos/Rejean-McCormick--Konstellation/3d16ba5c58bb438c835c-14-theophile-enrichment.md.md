# Théophile enriched — exemple d'intégration sémantique

Le corpus Théophile enrichi illustre une navigation argumentative : questions, positions documentées, thèmes, auteurs, sources et relations entre positions.

## Utilité architecturale

Il sert principalement à valider les affordances :

- `network` ;
- `argumentation` ;
- `evidential` ;
- `provenance` ;
- `temporal` lorsque les dates de source/réception sont disponibles ;
- `conflict` lorsque les divergences sont explicites.

## Recettes attendues

- Constellation ;
- Positions/arguments ;
- Traçabilité ;
- Chronologie si applicable ;
- Divergences si explicitement présentes.

## Limite

Les relations éditoriales entre positions ou auteurs ne doivent jamais être transformées en influence historique sans assertion canonique correspondante.

## Isolation

Théophile est un excellent golden corpus pour l'argumentation, mais il ne définit pas les concepts universels de Konstellation.
