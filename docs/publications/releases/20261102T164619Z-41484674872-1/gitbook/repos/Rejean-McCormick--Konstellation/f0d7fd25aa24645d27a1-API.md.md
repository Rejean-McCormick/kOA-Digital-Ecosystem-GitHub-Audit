# Local API and Public Contracts

The Node server exposes an HTTP API and built Astro UI assets. In the local profile, the expected URL is `http://127.0.0.1:4321`.

## Key endpoints

| Method | Route | Purpose |
| --- | --- | --- |
| GET | `/api/health` | Basic service health |
| GET | `/api/version` | Version and permitted build information |
| GET | `/api/kristals` | Reader catalog and current selection |
| GET | `/api/fleet` | Optional, locally authorized Manager preview |
| GET | `/api/bootstrap` | Registries, Lenses, and capabilities for the selected Kristal |
| GET | `/api/capabilities` | Visible capabilities |
| POST | `/api/query` | Query a selection |
| POST | `/api/facets` | Selection facets |
| POST | `/api/entity` | Entity details |
| POST | `/api/evidence` | Visible assertions/evidence |
| POST | `/api/constellation` | Derived constellation |
| POST | `/api/navigation/plan` | Compute a navigation plan |
| POST | `/api/navigation/project` | Build a bounded projection |

Additional endpoints (SA, Kompiler, metrics, exploration state) may be enabled depending on configuration and scopes. HTTP `404` on an **optional** module may simply mean it is disabled; a Kompiler `503` can indicate an unconfigured dependency.

## Minimal example

```powershell
Invoke-RestMethod http://127.0.0.1:4321/api/health
Invoke-RestMethod http://127.0.0.1:4321/api/kristals
```

In neutral mode, no Kristal is initially selected. The client handles selection; the presence of the catalog does not mean that every specialized reader's `bootstrap` is already ready.

## Security, context, and errors

- Roles filter visible content; scopes filter API actions.
- For nonlocal deployments, use the authentication mechanisms provided by the project.
- The server enforces Host/Origin controls, size limits, and Reader Policy.
- Structured errors typically include `error.code`, `error.message`, and `requestId`. Do not display sensitive details from private sources.

Refer to `docs/24-api-contracts.md` for request/response schemas. This wiki does not replace JSON Schemas or tests.
