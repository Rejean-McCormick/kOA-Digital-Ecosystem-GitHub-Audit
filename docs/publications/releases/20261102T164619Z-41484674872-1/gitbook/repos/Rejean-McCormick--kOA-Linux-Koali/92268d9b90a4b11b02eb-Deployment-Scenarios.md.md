## Profile selection

A scenario does not automatically determine one deployment profile. Capacity, connectivity, assurance, number of users, data sensitivity, build requirements and administrative model determine whether the system uses a lightweight endpoint, sovereign node, hub, build farm, control plane or high-assurance overlay.

See [Deployment choices](Deployment-Choices) and [Deployment profiles](Deployment-Profiles) for the technical model.
