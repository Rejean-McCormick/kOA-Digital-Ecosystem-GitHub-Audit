# kOA Digital Ecosystem

kOA is a system of systems connecting source acquisition, civic decisions, governed work, epistemic artifacts, consumer projections, platform/runtime controls and presentation composition through explicit contracts.

## System map

```text
External sources/providers
        ↓
    EncyKlopedia
        ↓
       Da’at
        ↓
      Kristal
        ↓
  consumer projections
   (UCKK / others)

Konnaxion  <------ adopted cross-system Profiles ------>  Orgo
    \                                                   /
     +---------------------> Da’at ---------------------+

Kristal
   ↓ Runtime Pack artifacts
kOA-Linux knowledge channel / Release Set
   ↓
kristal_runtime
   ↓
kOA Node Agent (privileged transition only when required)

Koali Spaces sits above admitted products as an optional presentation layer.
It does not acquire their business, workflow, epistemic or host authority.
```

## Owners

- **EncyKlopedia** — source discovery/acquisition, provider resolution, immutable evidence/provenance and corpus-harvest handoff.
- **Konnaxion** — civic/public state and DecisionRecords.
- **Orgo** — workflow/work state and durable external operations.
- **Da’at** — source/IK-to-Kristal mapping and ACL boundary.
- **Kristal** — referent semantics, epistemic artifacts and Runtime Pack semantics.
- **UCKK / Univers-Cité** — rebuildable scoped consumer projections, Moodle/campus materialization and derived indexes.
- **kOA-Linux** — platform profiles, trust/policy/resources, artifact admission and release-channel coordination.
- **`kristal_runtime`** — Runtime Pack verification, compatibility, active Runtime Pack state, activation/rollback receipts and runtime health.
- **kOA Node Agent** — narrow authorized node-local lifecycle and privileged host operations.
- **Koali Spaces** — optional shell/presentation composition and Space lifecycle.
- **Interaction Kernel** — target interoperability protocol/Profile layer where adopted.

## Knowledge authority rule

```text
acquisition evidence   ≠ epistemic validation
consumer projection    ≠ Kristal canon
consumer primary view  ≠ ecosystem ontology
derived glossary       ≠ parallel source of truth
```

See [Knowledge acquisition and projection](Knowledge-Projection).

## Runtime Pack activation

The earlier statement “kOA-Linux owns Runtime Pack activation” is too broad. `kristal_runtime` owns verification/compatibility/active-state records and activation/rollback receipts; kOA Node Agent performs only the narrow privileged host transition required by the active profile.

## Koali Spaces

Koali Spaces is presentation infrastructure. Space/application activation is a UI/composition lifecycle and must not be interpreted as Kristal Runtime Pack activation.
