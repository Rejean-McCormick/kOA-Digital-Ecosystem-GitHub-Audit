# King Klown / Kristal MEDIA — creative character pack

This pack is an **interpretive character-design layer**, not a modification of the Kristal canon.

**Input:** the user-provided `Kristal-King-Klown-4-2-0-MEDIA.zip` (v4.2.0-MEDIA, State v9). The archive provides registers, 60 universe events and semantic media mappings, **but no raster portrait files**.

**How to read the profiles**

1. **Source-supported** describes what the packaged registry, assertions or event ledger actually says. An event tagged `SOURCE_EXPLICIT_NON_GOVERNING` is part of a source branch and must not be silently promoted into governing canon.
2. **Creative interpretation** includes the psychological axes (0–6 complementary preferences), visual portraits where none exist, emotional palettes, fears, goals and speculative growth arcs. These are editable narrative proposals, *not* observed or psychologically measured facts.
3. A profile or linked card does not necessarily mean a separate person. King Klown, Colin Row, Ninja Arc-en-ciel and the primordial principle are **presentation modes of one declared continuity**. `L’Auteur (Hello World)` is a distinct *metafictional character within that work*, not an alias for the real-world author.
4. **Aïda Mansour and Aïda Éloïse must not be merged**: the source expressly distinguishes them.
5. The private civil name of `AUTHOR_REAL` must never be reconstructed or shown. No personal biological details are inferred about unnamed characters, and no culturally stereotyped costumes are invented.
6. Works, symbols, collectivities and infrastructure—including Rêvasseur, Le Rire Cosmique, Lumière Blanche, the Uyghur community and La Machine—are **not silently turned into people**.

## Usage

The profiles are built into the application. On an existing installation, Karacter 7.3 adds missing bundled characters on first launch without overwriting edited text or portraits. Select one or more universes using the sidebar chips; there is no longer a separate import button for built-in universes.

Each profile has a traceable information panel in the Create screen. Plain-text sheets are in `fiches/kristal/`. Complete machine-readable pack: `data/kristal-kk-media-pack.json`. Supporting source excerpts: `data/kristal-source-evidence.json`.

Generated images still require manual creation from Karacter prompts and dropping files into the portrait zone. No images were included in the supplied Kristal archive.
