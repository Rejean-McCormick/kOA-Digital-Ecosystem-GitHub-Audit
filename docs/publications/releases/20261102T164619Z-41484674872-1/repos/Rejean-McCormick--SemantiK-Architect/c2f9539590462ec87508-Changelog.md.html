# Changelog

## 2026-09-25 — Wiki v1 architecture alignment

The wiki now documents the implemented SemantiK Architect v1 architecture and runtime model.

Highlights:

- canonical `CommunicationRequest` / `SemanticGraph` / obligation model;
- separate `CommunicationPlan` and target-language `LanguagePlan`;
- two-phase lexical resolution;
- strict, versioned SA↔GF bridge;
- immutable RuntimeSets and explicit activation;
- capability profiles and binary production release gate;
- faithfulness/coverage model;
- SDK/CLI/HTTP surfaces;
- current ecosystem boundaries and semantic translation flow;
- language addition as GF artifact + conformance work rather than core branching.

The wiki is intentionally concise and avoids duplicating the deep architecture locks maintained with the source repository.
