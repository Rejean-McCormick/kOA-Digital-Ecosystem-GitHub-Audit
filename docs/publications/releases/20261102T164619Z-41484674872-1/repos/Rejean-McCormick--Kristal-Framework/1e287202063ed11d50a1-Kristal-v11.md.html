# Kristal v11 — Canonical Semantic Identity & Lexical Separation

**Draft:** `11.0.0-draft.4` · profile `kristal.semantic-identity/11.0` · **additive** to v6–v10.

A conforming **new v11 canonical semantic graph** uses only namespace-scoped semantic IDs for its *structural identities*. Meaning is stable independently of language and external authority systems. Labels are stored in separately versioned dictionaries, and Wikidata Q/P entries are joined through an independent crosswalk.

## New v11 artifacts

| Type (machine) | Responsibility |
|---|---|
| `kristal_identity_registry` | Issued KQ/KP/KA/KS identities, scoped by `namespace_id` |
| `kristal_semantic_graph` | KQ subjects/objects, KP predicates, KA assertions, KS sources and typed literal values |
| `kristal_lexical_dictionary` | Basic per-language KQ/KP labels and synonyms |
| `kristal_dictionary_catalog` | Per-locale file layers, priorities, explicit fallback, SHA-256 |
| `kristal_wikidata_lexical_record` | Immutable-per-snapshot imported Q/P labels/aliases/descriptions |
| `kristal_curated_dictionary` | Reviewed human changes, separate from imported files |
| `kristal_external_lexical_record` | Reviewed third-party terms with source, snapshot and rights |
| `kristal_external_crosswalk` | Versioned Q/P↔KQ/KP mapping decisions |
| `kristal_dik_coverage_report` | Deterministic KQ/KP-by-language report |
| `kristal_dik_conversion_plan` | Proposed, non-executable identity-field migration |
| `kristal_legacy_resolution_requests` | Explicit requests to resolve historical word-based identifiers |

## Boundary rules

- `SEMANTIC IDENTITY != LEXICAL LABEL != EXTERNAL ID`.
- Names are not IDs; duplicate names can point to different entities.
- A new internal ID is `KQ…`/`KP…`, never an invented Wikidata `Q…`/`P…`.
- A source string or paragraph is permitted as a **typed literal** but not a subject, predicate or opaque identity.
- `candidate` or `closeMatch` never substitutes for accepted, reviewed `exactMatch`.
- Historical v6–v10 states, their hashes, contracts and signatures are **not silently changed**.
