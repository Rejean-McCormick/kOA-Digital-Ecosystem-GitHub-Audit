# Compatibility: v6, v7 and v8

> **Historical baseline:** this page describes the compatibility contract as of v8. The inherited v9 compatibility model is [[Compatibility-v6-v7-v8-v9]]; for v10 see [[Compatibility-v9-v10]].

V8 is additive over v6/v7. Valid inherited artifacts remain valid without rewrite.

## Stable v8-era boundaries

- v6 portable state semantics and identity rules;
- v7 KQ/KP/KA/KS identity semantics;
- source/provenance/authority boundaries;
- disagreement, unresolved identity and scope;
- v8 lexical/query artifacts as optional companions.

## v9 note

V9 freezes these surfaces as inherited substrates and adds state/materialization architecture around them. It does not reinterpret this historical contract.
