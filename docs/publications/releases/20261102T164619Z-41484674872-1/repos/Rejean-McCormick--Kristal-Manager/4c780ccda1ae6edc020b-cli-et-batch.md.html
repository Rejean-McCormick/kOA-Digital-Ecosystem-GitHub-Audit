# CLI et batch — commandes livrées et futures

**Les commandes ci-dessous correspondent au module `operations_cli.py` livré dans le dernier overlay**, s'il a été installé. Les chemins contiennent des exemples Windows, à adapter à ton installation.

```powershell
cd C:\mycode\Kristal\Kristal-Manager
$Racine = 'C:\mycode\Kristal\locals'

# Inventaire et index des workspaces
python -m kristal_manager.operations_cli inventorier --root $Racine

# État de l'index (sans lancer de moteur)
python -m kristal_manager.operations_cli etat --root $Racine

# Analyse globale (peut reconstruire le catalogue)
python -m kristal_manager.operations_cli analyser --root $Racine

# Diagnostic V9 sur trois Kristals applicables dans l'ordre parcouru
python -m kristal_manager.operations_cli diagnostiquer --root $Racine --max 3

# Diagnostic V9 du dossier complet
python -m kristal_manager.operations_cli diagnostiquer --root $Racine
```

**Attention** : `--max 3` limite à trois workspaces parcourus, pas nécessairement aux trois premiers **applicables**. Les non-V9 sont consignés `NOT_APPLICABLE`. Ce batch **ne teste pas toutes les familles de Kristals**.

```powershell
# Import historique Arketype — observations, non décisions
python -m kristal_manager.operations_cli importer-arketype 'C:
apports\RAPPORT_ARKETYPE_STRUCTURE.json'

# Import d'un ancien bilan CSV — toujours historique non vérifié
python -m kristal_manager.operations_cli importer-anciens-diag 'C:
apports\BILAN-DIAGNOSTICS.csv' --root $Racine
```

## Sorties

Les diagnostics sont enregistrés hors des Kristals, sous un répertoire de preuves obtenu depuis les préférences Manager (`ui_prefs.settings_path().parent / diagnostics`) et un sous-dossier batch. La CLI imprime un JSON de bilan. Le contenu complet peut inclure des données sensibles; ne pas mettre dans Git.

## Commandes futures (NON IMPLÉMENTÉES)

`manager run --profile auto --resume`, `manager export --manifest`, `manager verify-evidence`, `manager migrate-db --dry-run` sont des propositions d'interface, **pas** des commandes à essayer aujourd'hui.
