# Naming and Scope

> **Reading model:** The main path explains what the kOA ecosystem enables. The technical reference explains how kOA-Linux hosts, isolates, verifies, and operates those capabilities. Product-specific details remain in each subsystem's own documentation.

## Four scopes

### kOA initiative

The broader body of theory, civic principles, cultural work, research, narrative, and institutional proposals.

### kOA ecosystem

The interoperating digital systems that support the cycle from knowledge to deliberation, decision, execution, and memory.

### kOA-Linux Operating System

The sovereign runtime and deployment environment. It hosts selected capabilities and enforces local isolation, resources, trust, lifecycle, offline behavior, recovery, and integration boundaries.

### Product systems and modules

Konnaxion, Orgo, Kristal, Ariane, SenTient, SemantiK Architect, and other products retain their own internal documentation and authority. Konnaxion also contains named modules and submodules documented in its own Wiki.

## Naming rule

This Wiki must not use **kOA-Linux** as a synonym for the complete kOA ecosystem. It may explain the ecosystem because the operating system exists to run it, but it must always identify which product owns a capability.

UCKK is an external Moodle platform, not an internal kOA-Linux subsystem. The local kOA Mediatheque and UCKK exchange remain secondary infrastructure topics, not the definition of the ecosystem.
