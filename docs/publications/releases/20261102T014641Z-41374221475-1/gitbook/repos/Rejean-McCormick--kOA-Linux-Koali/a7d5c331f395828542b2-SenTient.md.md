# SenTient

> **Reading model:** The main path explains what the kOA ecosystem enables. The technical reference explains how kOA-Linux hosts, isolates, verifies, and operates those capabilities. Product-specific details remain in each subsystem's own documentation.

SenTient is an optional semantic-processing and reconciliation workbench for transforming ambiguous or fragmented inputs into structured candidates.

Use:

- [SenTient repository](https://github.com/Rejean-McCormick/SenTient)
- [Public overview](https://initkoa.org/technology/sentient)

Its outputs remain candidates until accepted by an authoritative workflow. It is optional, isolated, and not part of lightweight baselines by default.
