# Capability and Ownership Map

> **Reading model:** The main path explains what the kOA ecosystem enables. The technical reference explains how kOA-Linux hosts, isolates, verifies, and operates those capabilities. Product-specific details remain in each subsystem's own documentation.

| Capability | Product owner | Role of kOA-Linux |
| --- | --- | --- |
| Portable validated knowledge | Kristal | verify, activate, store, expose, and distribute artifacts locally |
| Candidate semantic reconciliation | SenTient | optional isolated execution and resource limits |
| Learning and knowledge sharing | Konnaxion / KonnectED | local hosting, identity, storage, offline packages, controlled exchange |
| Structured deliberation | Konnaxion / Ethikos | trusted runtime and integration boundaries |
| Credibility and advisory readings | EkoH and Smart Vote | preserve policy, evidence, audit, and separation from machine privilege |
| Project and innovation collaboration | keenKonnect | local services, resources, files, and external boundaries |
| Cultural memory and creator networks | Kreative / Konservation / Kontact | local storage, rights enforcement, privacy, backup, and publication controls |
| Organizational execution | Orgo | isolation, local databases and queues, identity, availability, recovery |
| Multilingual realization | SemantiK Architect | activate verified language artifacts and bound runtime resources |
| Assisted navigation | Ariane | host local navigation, authorize actions separately, bound external voice/AI |
| Local media authority | kOA Mediatheque | complete internal ownership |
| External learning distribution | UCKK | explicit, optional publication/import integration only |
| Policy and rights enforcement | Governance Policy Runtime | complete internal ownership |
| Offline and sovereign operation | kOA-Linux | primary owner |

Cross-system outcomes—such as group-to-organization, collective judgment-to-execution, multilingual assisted navigation, or culture-to-governance—must identify the owner of every transition.
