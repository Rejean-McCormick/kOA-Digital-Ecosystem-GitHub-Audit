# Offline-First Operation

> **Reading model:** The main path explains what the kOA ecosystem enables. The technical reference explains how kOA-Linux hosts, isolates, verifies, and operates those capabilities. Product-specific details remain in each subsystem's own documentation.

Offline capability is a governance guarantee: a community should be able to preserve local knowledge, work, evidence, and continuity without permanent dependence on a cloud provider.

Depending on the active profile, local operation can include:

- Kristal knowledge and provenance;
- Ariane navigation graphs;
- Konnaxion portable resources and selected local spaces;
- Orgo cases, tasks, routing, and queues;
- kOA Mediatheque files and imported learning packages;
- deterministic multilingual rendering with installed artifacts;
- local policy evaluation, backup, and recovery.

External publication, remote discovery, federation, and optional AI services wait for connectivity. The system must show what is local, queued, stale, unavailable, or awaiting review.
