EKOLE - TANDEM / ORGO / P1 (preview enseignant synthétique)

Déposer/extrair ce ZIP à la racine C:\mycode\Ekole\ekole
Puis double-cliquer dans cet ordre :
  PREVIEW_EKOLE_TANDEM_P1.cmd
  INSTALL_EKOLE_TANDEM_P1.cmd
  VERIFY_EKOLE_TANDEM_P1.cmd
Rollback si nécessaire : ROLLBACK_EKOLE_TANDEM_P1.cmd

Périmètre : code Ekole, aucun élève réel, service, corpus frère, DB, Orgo, VPS ou Docker modifié.
Le preview enseignant est synthétique, désactivé par défaut, sans données personnelles.
Les tests autonomes sont exécutés sur une copie temporaire, sans appels réseau externes.
Autres tests de corpus: les dépôts frères ekole-quebec et ecole-pastorale sont requis.
Voir docs/TANDEM_EKOLE_ORGO_PREVIEW_P1.md après installation.
