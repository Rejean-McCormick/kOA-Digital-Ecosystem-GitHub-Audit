# Open Questions and Trade-offs

These are **choices still requiring validation**, not settled production decisions.

| Question | Reference assumption | Decision owner / evidence required |
|---|---|---|
| Top-third allocation | `ceil(n/3)` | Educational review of the policy |
| Ranking use | Only with comparable scores | Validated assessment and fairness evidence |
| Free choice vs. guided allocation | Configurable per session | Teacher / institution |
| Variable class sizes | Explicit role capacities and alternatives | Edge-case trials |
| Affinities and aversions | Minimal, temporary, private signals | School governance, access, retention |
| Guardianship conditions | Rotation, acquisition, supervised transfer | User research and classroom testing |
| Kristal questions | Topic and question selection | Usability and accessibility testing |
| Historical perspectives | Contextualized sources with controlled rights | Experts and relevant communities |
| SSO, permissions, retention | External service ports | Institutional decision-makers |
| Multilingual product | French first in original reference | Editorial and language policy |

## How to resolve them

For each decision, record learning purpose, chosen solution, rejected alternatives, risks to minors, technical dependencies, consequences for knowledge access, tests, and migration plan. Create an ADR for choices affecting more than one capsule.
