# Offline

**Classe : Cible produit**

La page Offline explique clairement ce qui reste utilisable : routes `available`, `cached_read_only`, `degraded`, `unavailable`.

Elle peut afficher le dernier Space validé, les modules locaux et les opérations différées déclarées.

Elle ne promet pas que toutes les applications sont offline simplement parce que le shell est local.
