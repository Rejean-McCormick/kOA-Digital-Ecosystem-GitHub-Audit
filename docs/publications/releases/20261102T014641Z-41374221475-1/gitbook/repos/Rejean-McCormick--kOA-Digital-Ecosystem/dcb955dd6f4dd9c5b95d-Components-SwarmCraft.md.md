# SwarmCraft

SwarmCraft is an execution capability for governed tasks. It consumes inputs that are eligible under the applicable workflow, Reader Policy and deployment policy, executes bounded work, and emits telemetry/outcomes.

It does not own Konnaxion civic state, Orgo workflow authority, Kristal validation/recognition state or kOA-Linux host activation.

## Knowledge use

SwarmCraft may consume Runtime Packs or other explicitly eligible artifacts. It must preserve epistemic/source status and must not silently turn Working, disputed or low-valuation material into recognized reference material.

New factual observations or claims produced during execution must return through an appropriate governed knowledge/provenance path; execution side effects do not directly mutate Kristal Reference Exchanges.

## Operational constraints

- execute only authorized tasks;
- use source-owned refs rather than direct cross-system DB mutation;
- preserve audit/correlation metadata;
- report outcomes back to the owning workflow/integration path;
- obey local platform admission/privilege limits when running on kOA-Linux.
