# Installation

## Requirements

- A reasonably current desktop browser with JavaScript and **IndexedDB** enabled.
- The extracted Karacter 7.4 project folder, including `index.html`, `src/`, and `assets/`.
- Python 3 **only if** you choose the recommended local-server workflow.
- No `npm install`, account, database server, or paid image API is needed for ordinary local use.

## Recommended: local server

Extract the application ZIP, open a terminal in the `Karacter7` folder, then run:

```sh
python -m http.server 8080
```

Visit **http://localhost:8080** in your browser. On Windows, `py -m http.server 8080` may work if `python` is not on your PATH.

This remains a **local** app: the Python server serves files from your computer; it does not create a cloud account. Keep the same browser profile, host, and port when reopening the app because IndexedDB is tied to the browser origin.

## Alternative: open directly

Double-click `index.html`. The interface may work under `file://`, but local storage behavior differs across browsers and paths. For a collection you intend to keep, prefer the local-server method and maintain full backups.

## Updating from an older release

1. In the existing version, export a **complete Backup ZIP**.
2. Keep that ZIP in a folder separate from the app.
3. Extract the new version without mixing old and new `src` files.
4. Start it using the **same local origin** if you want to retain browser data.
5. Let the one-time universe migration complete. Missing built-in characters are merged without overwriting personal edits; existing custom universes are retained.
6. If your old browser data does not appear, use **Import file** with a supported full backup after verifying you are willing to replace the current workspace.

The **King Klown** and **Blank Universe** profiles are already bundled. Do not import separate universe packs just to see them.
