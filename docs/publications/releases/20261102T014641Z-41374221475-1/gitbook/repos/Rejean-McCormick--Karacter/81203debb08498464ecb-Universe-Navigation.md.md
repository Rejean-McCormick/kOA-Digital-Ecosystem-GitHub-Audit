# Universe Navigation

Karacter 7.4 organizes characters under **universes**. The interface displays two built-in universes in a defined order, with support for additional user-created universes.

## Default library

| Order | Universe | Fresh-install content |
|---|---|---|
| 1 | **King Klown** | 39 profiles drawn from Kristal MEDIA and King Clown Canon packs |
| 2 | **Blank Universe** | John Doe, one almost empty starter character |

The **All universes** button displays characters across every universe. It does not create a third universe. On an upgraded installation, you may also see your previously created universes or characters, so counts can differ.

## Show one or several universes

1. Look for the universe chips above the character list in the left sidebar.
2. Select **King Klown** or **Blank Universe** to show just that universe.
3. Select another universe chip to include **both**. Selected chips are cumulative.
4. Select **All universes** to reset the filter and show the entire library.

The search box further narrows results by name, role, keywords, universe, motivation and contradiction. **Filtering changes what is shown, not the underlying records.** The gallery uses the same universe visibility filter.

## Create new characters in a universe

When exactly one universe is selected, new characters and new characters created from templates are placed there. Otherwise, Karacter generally uses the currently active character's universe. Check the universe selector under the character's **Create** tab and change it if necessary.

## What happened to kOA, Kristal MEDIA and Canon?

Version 7.4 unifies the former built-in categories **`kOA`**, **`King Klown · Kristal MEDIA`**, and **`King Klown · Canon narratives`** under **King Klown**. The original provenance remains in the character's source metadata and an extension recording prior universe mappings; the source packs are not erased.

This is a **one-time, non-destructive migration**. It preserves character IDs, personal edits, artwork, relationships, and story history. Characters deliberately deleted after the migration should not reappear on every subsequent launch. The earlier sample Mira, if already saved, is kept; she is not seeded on fresh installations.

## Universes vs. visual themes

- **Universe:** narrative grouping and library filter (King Klown, Blank Universe, or your own).
- **Visual theme:** how the same character is depicted (alien, hockey, mythology, etc.).

Switching the visual theme does **not** transfer a character to a different universe or change its psychological profile.
