# Getting Started

Karacter opens locally in a modern browser. No account, hosted API, or build step is required for the standard application.

## Your first five minutes

1. [Install and open Karacter](Installation), preferably using `http://localhost:8080` for a stable browser storage origin.
2. In the left sidebar, choose **King Klown** to explore the built-in catalogue, or **Blank Universe** for John Doe.
3. Choose a character. The five main tabs are **Create**, **Understand**, **Simulate**, **Story**, and **Gallery**.
4. Switch the top-level **Explorer / Studio** control to choose a shorter or deeper editing experience.
5. Make a small edit, wait for **Saved locally**, then export a complete **Backup ZIP**.

## The five screens

| Screen | What you do | What changes |
|---|---|---|
| **Create** | Edit identity, visual signature, artwork prompts | Character and visual metadata |
| **Understand** | Edit polarities, emotions, motivation, conflict, relationships and milestones | Psychological/narrative profile |
| **Simulate** | Choose a scenario, stakes, optional other character; generate or compare reactions | Hypothetical runs (not canon) |
| **Story** | Accept a reaction as an event, edit outcomes, review growth | Author-approved story memory |
| **Gallery** | Browse, import, crop, download or remove artwork | Per-character image slots |

The current **universe filter** affects which characters appear in the sidebar and gallery. Filtering **does not delete or move** the other characters.

## Create your first original character

- Choose **Blank Universe** and select **John Doe**, or click **New character** to create another profile.
- Give the character a name, role, keywords, and a memorable visual signature.
- Open **Understand** and add polarities appropriate for the character. John Doe starts with **no** preset axes, emotions or narrative conflict. This is intentional.
- Give the character a *want*, a *need*, and at least one source of tension.
- In **Simulate**, pick a situation and inspect three plausible paths. You can edit the suggestions before using them.
- Use **Make canon** only when you want a choice to become a lasting story event.

## Important distinctions

**Personality vs. emotions:** preferences describe habits; emotions change with situations. **Simulation vs. canon:** a generated suggestion is only a possibility until the author approves it. **Theme vs. universe:** a *universe* groups characters, while a *visual theme* changes how a character is illustrated.

For a guided explanation of each concept, see [Personality Polarities](Personality-Polarities), [Simulations and Comparison](Simulations-and-Comparison), and [Visual Themes and Prompts](Visual-Themes-and-Prompts).

## Before you explore extensively

The application uses IndexedDB on the local browser origin. Browser data can be cleared, restricted, or isolated by URL. **Export complete ZIP backups regularly**; a TXT character sheet is not a substitute for a backup containing artwork and story history.
