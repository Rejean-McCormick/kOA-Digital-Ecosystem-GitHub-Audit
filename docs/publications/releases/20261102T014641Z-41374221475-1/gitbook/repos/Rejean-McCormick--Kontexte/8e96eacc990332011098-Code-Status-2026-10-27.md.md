The README and `docs/RELEASE_0_4.md` document the **Local Scenario Studio** on `http://127.0.0.1:8769/`: a teacher-oriented offline rehearsal of 60 localized Québec frames, synthetic solo/duo missions, fictional Klownkoins and demonstration evidence. The Studio is local; it is not an authenticated classroom runtime.

## Tandem P1 handoff

`docs/ekole-orgo/TANDEM_P1_EKOLE_PREVIEW_EXPORT.md` and `tests/test_tandem_ekole_handoff.py` describe the deterministic, synthetic teacher-preview export toward Ekole. It is not a trusted Orgo Task, Case or admission decision, and no actual child identities are involved. **Orgo alone owns operational workflow state**; Ekole owns pedagogical presentation/evidence and Kontexte owns scenario descriptions. These responsibilities must not be duplicated as a new Kontexte runtime.

Real WorldRelease, identity, teacher approval, trusted admissions, and production evidence handling need separate qualified implementations.
