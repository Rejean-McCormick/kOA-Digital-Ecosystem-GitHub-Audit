# Définition produit

**Classe : Normatif**

Koali Spaces est un environnement d’expérience contextualisé qui transforme des contributions d’interface admises en un espace utilisateur cohérent. Il agit comme **composition host intégré optionnel** : les produits propriétaires peuvent conserver une interface standalone fonctionnelle lorsque Koali Spaces est absent.

Un même nœud kOA peut présenter des expériences différentes — école, travail, communauté, projet, personnel — sans modifier les autorités sous-jacentes.

Le produit fournit quatre fonctions fondamentales :

1. **Composer** : sélectionner et ordonner les produits/modules d’interface d’un Space.
2. **Projeter** : sélectionner une surface déclarative d’un produit (Control, My Work, Operations, Supervisor, etc.) sans dupliquer ses pages.
3. **Orienter** : fournir navigation globale, contexte actif et commandes de shell.
4. **Présenter** : rendre pages Koali, composants enregistrés et applications propriétaires.
5. **Dégrader proprement** : conserver une expérience explicite lorsque capabilities, réseau ou runtime changent.

Koali Spaces est indépendamment versionné et remplaçable. La disparition du composition host ne doit pas effacer ou transformer l’état métier des systèmes propriétaires, ni rendre non fonctionnelle une interface produit qui déclare supporter le mode standalone.
