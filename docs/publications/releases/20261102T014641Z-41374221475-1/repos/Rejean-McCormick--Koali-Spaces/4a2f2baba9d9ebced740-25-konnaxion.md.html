# 25. Konnaxion : verrou de propriété de l'UI

Konnaxion est un sous-système intégré mais indépendant dans sa frontière interne.

`LOCK-KS-SURF-087` — **Koali n'adopte pas les modèles Konnaxion comme ses propres modèles.**

`LOCK-KS-SURF-088` — **Koali n'adopte pas les routes Konnaxion comme routes shell globales ; elles restent sous le namespace de module.**

`LOCK-KS-SURF-089` — **Koali ne remplace pas le shell interne Konnaxion.**

`LOCK-KS-SURF-090` — **Les surfaces et modules Konnaxion gardent leur service-layer/API access interne.**
