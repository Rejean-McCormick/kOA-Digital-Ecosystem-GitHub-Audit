# Scope et non-goals

**Classe : Normatif**

## Dans le scope

- shell global ;
- composition d’un Space ;
- navigation déclarative ;
- présentation de capability projections ;
- routing de présentation ;
- thèmes, localisation et accessibilité ;
- surfaces globales ;
- hébergement de surfaces propriétaires ;
- gestion locale de l’état de présentation ;
- packaging et démarrage du runtime Koali Spaces ;
- diagnostics de présentation.

## Hors scope

- décisions d’autorisation ;
- identité et trust root ;
- gouvernance ;
- resource scheduling ;
- données métier ;
- mutation directe des stores propriétaires ;
- remplacement du lifecycle broker kOA ;
- moteur de workflow générique ;
- synchronisation implicite entre systèmes ;
- réimplémentation des applications intégrées.

Koali Spaces est un produit d’expérience, pas un monolithe applicatif.
