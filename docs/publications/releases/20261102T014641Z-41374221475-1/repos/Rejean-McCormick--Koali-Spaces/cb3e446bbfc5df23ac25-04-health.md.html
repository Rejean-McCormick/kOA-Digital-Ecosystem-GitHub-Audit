# Interface Health

**Classe : Cible produit**

Health présente l’état de l’expérience : Space actif, shell readiness, runtime presentation, modules admis, capabilities snapshot disponible, network state, surfaces unavailable/degraded et version du runtime.

Il ne remplace pas les diagnostics complets kOA/LevelUpDiag. Les diagnostics de sécurité, resources ou governance restent chez leurs owners.
