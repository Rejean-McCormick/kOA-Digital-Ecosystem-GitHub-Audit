# Kristal v6 alignment — 2026-10-01

Orgo_Worlds remains a routing/provenance control-plane sibling. The main Orgo product now owns the active Kristal Standard 6.0.0 / Interaction Kernel v2 integration.

Worlds may reference a Kristal v6 artifact, its digest, World/release routing context and provenance. It must not copy the main Orgo IK modules, Da’at/Kristal adapters, Work runtime, or actionability execution logic.

This preserves the existing separation rule while aligning terminology with the ecosystem v6 boundary.
