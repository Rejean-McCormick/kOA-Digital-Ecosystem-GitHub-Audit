# A System of Systems

> **Reading model:** The main path explains what the kOA ecosystem enables. The technical reference explains how kOA-Linux hosts, isolates, verifies, and operates those capabilities. Product-specific details remain in each subsystem's own documentation.

## Why not one platform

The architecture spans public collaboration, organizational execution, validated knowledge, semantics, language, interfaces, culture, governance, storage, identity, and infrastructure. One monolith would concentrate excessive authority and become difficult to evolve or exit.

kOA therefore separates product ownership while connecting the products through a common knowledge-to-action cycle.

## Ecosystem map

| Layer | Systems and modules | Primary role |
| --- | --- | --- |
| Knowledge and semantic artifacts | Kristal, SenTient | structured knowledge, provenance, candidate reconciliation, portability |
| Public learning and collaboration | Konnaxion / KonnectED, keenKonnect, Kreative | learning, projects, culture, public participation, creation |
| Deliberation and judgment | Ethikos, Korum, Konsultations, EkoH, Smart Vote | disagreement mapping, consultation, decision procedures, advisory readings |
| Organizational execution | Orgo | signals, cases, tasks, roles, routing, escalation, closure, insights |
| Language and navigation | SemantiK Architect, Ariane | multilingual realization, semantic interfaces, assisted navigation |
| Local media and exchange | kOA Mediatheque, optional external UCKK exchange | local private media authority and explicit learning-content exchange |
| Governance and trust | Governance runtime, identity, audit, receipts | authorization, disclosure, consent, recourse, evidence |
| Sovereign runtime | kOA-Linux | profiles, isolation, resources, activation, offline continuity, recovery |

## Cooperation rules

1. Each system owns its internal state and product rules.
2. Exchanges use explicit artifacts, APIs, events, tasks, and receipts.
3. Advisory credibility signals do not silently become sovereign decisions.
4. Optional AI does not create invisible authority.
5. Failure of one system does not authorize another to absorb its role.
6. Local autonomy and global interoperability coexist through portable, governed exchanges.
