# KOMPOSE Glossary

| Term | Definition |
|---|---|
| **Capsule** | Versioned educational scenario executed by a group |
| **Session** | One execution of a capsule for a cohort |
| **Entry Door** | Secure browser-based session admission point |
| **Participant** | Student represented by an opaque, session-scoped identifier |
| **Role** | Assigned character or responsibility with missions and capacity |
| **Diagnostic** | Assessment primarily intended to guide learning adaptation |
| **Casting** | Role selection and allocation subject to policies and constraints |
| **Hard constraint** | Rule that cannot be broken: safety, rights, capacity, accessibility |
| **Soft constraint** | Preference satisfied where feasible without violating hard rules |
| **Affinity / aversion** | Private teacher-held signal about collaboration to encourage or avoid |
| **Kristal** | Structured, sourced, contextualized, versioned knowledge unit |
| **Guardian / Custody** | Participant temporarily responsible for mediating a Kristal |
| **AccessGrant** | Temporary permission to consult a Kristal |
| **Prompt** | Scripted message emitted after an authorized event |
| **Mission** | Activity with goals, prerequisites, and completion criteria |
| **Phase** | Shared milestone in a capsule's progression |
| **Event** | Timestamped domain fact used to coordinate modules |
| **Projection** | Audience-filtered view of a domain state |
| **Port / adapter** | Integration contract and its implementation for another service |
| **ADR** | Architecture Decision Record: a reasoned design choice |
| **CLI** | Local command-line demonstration, not a deployed web API |
