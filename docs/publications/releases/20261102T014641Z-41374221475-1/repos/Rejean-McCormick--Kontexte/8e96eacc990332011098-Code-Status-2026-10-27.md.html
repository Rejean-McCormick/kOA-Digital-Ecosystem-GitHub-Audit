# Source-Verified Code Status — October 27, 2026

> **Scope:** local source snapshot dated October 27, 2026, compared with the supplied wiki pages. Tests were not rerun, and the live GitHub Wiki was not checked.

## Implemented reference surfaces

`pyproject.toml` declares **Kontexte 0.4.0**. The README and `docs/RELEASE_0_4.md` document the **Local Scenario Studio** on `http://127.0.0.1:8769/`: a teacher-oriented offline rehearsal of 60 localized Québec frames, synthetic solo/duo missions, fictional Klownkoins and demonstration evidence. The Studio is local; it is not an authenticated classroom runtime.

## Tandem P1 handoff

`docs/ekole-orgo/TANDEM_P1_EKOLE_PREVIEW_EXPORT.md` and `tests/test_tandem_ekole_handoff.py` describe the deterministic, synthetic teacher-preview export toward Ekole. It is not a trusted Orgo Task, Case or admission decision, and no actual child identities are involved. **Orgo alone owns operational workflow state**; Ekole owns pedagogical presentation/evidence and Kontexte owns scenario descriptions. These responsibilities must not be duplicated as a new Kontexte runtime.

## Remaining constraints

Curriculum mappings are candidate/internal references, not official Québec accreditation. Role previews must not be mistaken for permission to disclose private fragments. Real WorldRelease, identity, teacher approval, trusted admissions, and production evidence handling need separate qualified implementations.
