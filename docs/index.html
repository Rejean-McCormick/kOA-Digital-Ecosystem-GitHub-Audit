Comment ?How?
Publication dans GitHub Actions
  1. Ouvre le lien, puis clique sur Run workflow.
  2. Choisis la branche main et le mode : all (tous les dépôts) ou selected (dépôts choisis).
  3. Règle preview_only sur true pour vérifier, ou false pour publier.
  4. Clique sur Run workflow, puis vérifie les coches vertes des jobs.

Le mode republish met à jour la présentation sans recollecter les dépôts.

Publish through GitHub Actions
  1. Open the link and click Run workflow.
  2. Select the main branch and mode: all (all repositories) or selected (chosen repositories).
  3. Set preview_only to true to preview, or false to publish.
  4. Click Run workflow, then check that the jobs succeed.

republish updates the presentation without recollecting repositories.
