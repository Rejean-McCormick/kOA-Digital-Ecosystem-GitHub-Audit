# Historical evidence review

The Windows local dashboard now includes a private **Revue des 245** view: 49 official repositories, with five independent qualification stages each. Historical sources and their limitations are browsable by repository, stage, and document.

This is a **review** rather than a certification import. You must explicitly review and save each decision in the **Certification & profils** tab. No stage changes when a historical report is merely discovered.

Source documents are only available in the downloaded application package's ignored `private_evidence/` directory. They are not published to GitHub Pages. When a manually approved claim references the historical review, a dated campaign stores a verified private copy of that review for long-term provenance.

See [`docs/HISTORICAL_EVIDENCE_REVIEW.md`](../docs/HISTORICAL_EVIDENCE_REVIEW.md) in the application package for the complete walkthrough, provenance limits, and local browser instructions.
